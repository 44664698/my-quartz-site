#### 0.1.1.1 1、Requests

当涉及到发出 HTTP 请求以与网站或 API 交互时，Requests 是一个强大的工具，可以使此任务变得简单而高效。有了它，你可以自动执行任务，例如定期从 API 获取数据，甚至在网站上提交表单。

从本质上讲，Requests 允许我们发送 HTTP 请求并接收 HTTP 响应。其中包括 GET、POST、PUT、DELETE、HEAD、PATCH 和 OPTIONS。Requests 的美妙之处在于它的简单性。只需一行代码即可发送简单的 HTTP 请求。

例如，以下是发送 GET 请求的方法：

```
import requests
response = requests.get('https://api.github.com')
print(response.status_code)
```

在此示例中，我们向 GitHub 的 API 发送 GET 请求，并将响应存储在响应对象中。通过响应对象，你可以访问返回的数据、状态代码、标头等等。

要访问服务器返回的实际数据，你可以使用 .json() 方法。

```
data = response.json()
print(data)
```

#### 0.1.1.2 2、BeautifulSoup

BeautifulSoup 是一个让网页抓取变得轻而易举的 Python 库。

想象一下这样的情况：你想要从网站提取一些数据，但没有可用的 API。这就是网络抓取的用武之地，而 BeautifulSoup 可以说是完成这项工作的最佳工具之一。

BeautifulSoup 帮助我们解析 HTML 和 XML 文档，使导航、搜索和修改解析树变得更加容易。有了它，你可以轻松地从网站中提取有用的数据，例如新闻网站的标题或电子商务网站的产品信息。

要使用 BeautifulSoup，你首先需要将其与 Requests 库一起安装。我们将使用 Requests 来获取页面的 HTML 内容，然后使用 BeautifulSoup 来解析它。

```
import requests
url = 'https://www.python.org/blogs/'
response = requests.get(url)
html = response.content

from bs4 import BeautifulSoup
soup = BeautifulSoup(html, 'html.parser')


```

现在，你可以使用 BeautifulSoup 的方法来导航 HTML 树。

titles = soup.find_all('h3', {'class': 'blogtitle'})  
for title in titles:  
    print(title.text.strip())

#### 0.1.1.3 3、Selenium

Selenium 是一个功能强大的 Python 库，它不仅是 Web 测试的主要工具，而且还是自动化 Web 浏览器的救星。无论是填写表单、模拟鼠标点击，甚至像人类用户一样浏览网站，Selenium 都可以处理。

Selenium 本质上使你能够以比 BeautifulSoup 更高级的方式与网页交互。BeautifulSoup 只允许你解析静态 HTML 内容，而 Selenium 与页面上的 JavaScript 交互，允许你处理动态内容。

```
import time
from selenium import webdriver

# 1、创建Chrome实例 。
driver = webdriver.Chrome()

# Go to Google
driver.get('https://www.google.com')
# Find the search bar
search_bar = driver.find_element("name", "q")
# Type 'Python'
search_bar.send_keys('Python')
# Submit the form
search_bar.submit()
time.sleep(5)


```

#### 0.1.1.4 4、Pandas

Pandas 是数据处理中必会的一个强大 python 库，该库提供了有效操作结构化数据所需的数据结构和函数。

Pandas 特别适合不同类型的数据，例如：具有异构类型列的表格数据（如 Excel 电子表格）、有序和无序时间序列数据，甚至具有行和列标签的任意矩阵数据。

```
import pandas as pd

# Create a simple dataframe
data = {'Name': ['John', 'Anna', 'Peter'],
        'Age': [28, 24, 33]}
df = pd.DataFrame(data)

print(df)


```

我们在这里所做的是创建一个允许灵活操作数据的数据结构。我们可以轻松地对数据帧进行排序、过滤、分组和应用各种转换。

例如，我们过滤掉30岁以上的人。

```
# Filter dataframe
filtered_df = df[df['Age'] > 30]
print(filtered_df)
```

#### 0.1.1.5 5、numpy

我们要讨论的下一个 Python 库是 NumPy。

如果你热衷于数值计算，你会发现这一点特别有用。NumPy 广泛应用于学术界和工业界，用于科学计算、数据分析和机器学习等各种任务。

NumPy 提供对数组的支持，数组类似于 Python 中的列表，但可以具有任意数量的维度，并且在内存使用和计算速度方面更加高效。它们在处理大型数据集和执行数学运算时特别有用。

```
import numpy as np

# Create a numpy array
arr = np.array([1, 2, 3, 4, 5])
# Add 10 to each element
new_arr = arr + 10
print(new_arr)


```

使用 NumPy，你还可以在数组级别执行各种数学运算，例如加法、减法、平方、平方根等。此外，还提供平均值、中位数和标准差等统计分析函数。

#### 0.1.1.6 6、PyAutoGUI

PyAutoGUI 是一个强大的 Python 库，可让你以编程方式控制鼠标和键盘。它是一个强大的工具，可以自动执行需要用户与界面交互的任务。无论你是想自动单击按钮还是在表单中输入内容，PyAutoGUI 都能满足你的需求。

```
import pyautogui

# Move the mouse to position (100, 150)
pyautogui.moveTo(100, 150)

# Perform a left click
pyautogui.click()

# Type the message 'Hello, world!'
pyautogui.write('Hello, world!')


```

这只是 PyAutoGUI 功能的冰山一角。它支持复杂的操作，例如拖放、滚动和处理警报框等。

#### 0.1.1.7 7、Schedule

Schedule 模块是一个第三方库，允许你安排 Python 函数按预定义的时间或间隔运行。它具有简单直观的语法，可让你以人类可读的方式表达调度逻辑。例如，你可以编写如下代码来每 10 分钟运行一个函数：

```
import schedule
import time

def do_something():
    print("Doing something...")

        # Schedule the function to run every 10 minutes
    schedule.every(10).minutes.do(do_something)

        # Keep the program running in a loop
    while True:
        # Run any pending tasks
        schedule.run_pending()

                # Wait for one second
        time.sleep(1)


```

Schedule 是一个简单而强大的工具，用于调度 Python 脚本。它可以帮助你自动化任务并简化工作流程。但是，它并不能替代更高级的调度程序，例如 cron 或 celery，后者提供更多功能和灵活性。
