原创  渔夫  程序员渔夫 

 各位小伙伴大家好，我是程序员渔夫。  

 今天给大家安利一波，最近一直在捣鼓一些小东西，发现了一个Python库，挺好玩的，这里给大家介绍一下。  

![](https://g1proxy.wimg.site/sYseaRyqjfU6sI2R29gz5ZBIC44LRbgODImujSeQwhho/https://mmbiz.qpic.cn/mmbiz_png/7Zs1OPEmhRespsTG5ib5XjYdMSSNUpIlicLjDcDPXNj5QPvH6PDicUicNCZYuRrXCCnwmATUGpyJWKTpFLZOxUzJtA/640?wx_fmt=png&from=appmsg)

 faker，这个库的主要作用是随机生成一系列人物信息，比如你在测试接口时，需要填写一个身份证号，然而你为了保护自己的隐私，不想用自己的，那么你可以试试这个库了。

 因为身份证号是18位的，不是随便乱写18个数字就可以了。

 首先需要你通过pip安装一下：  

 pip install faker  

 接下来我们来看一下使用的方法：

`from faker import Faker` `# 设置语言` `faker = Faker('zh_CN')` `# 生成数据` `print('姓名:', faker.name())                # 随机输出中文姓名` `print('联系方式:', faker.phone_number())    # 随机输出电话号码` `print('地址:', faker.address())             # 随机输出地址` `print('公司:', faker.bs())                  # 随机输出公司` `print('工作:', faker.job())                 # 随机输出工作` `print('邮箱:', faker.company_email())       # 随机输出邮箱` `print('文本:', faker.text())                # 随机文本` `print('身份证号:', faker.ssn())             # 随机身份证号码`

 然后我们看一下输出。

![](https://g1proxy.wimg.site/sGF2MOeraf0ZwSHDhOYrLAEDRfgtr6J9r_tAbX56awiw/https://mmbiz.qpic.cn/mmbiz_png/7Zs1OPEmhRespsTG5ib5XjYdMSSNUpIlicuw2IHT54DUpGEf2qQO3TXRDUZQsU0wVNNnwOss0lFM97zLsHTZYBqw/640?wx_fmt=png&from=appmsg)

 可以从上图看到身份证号已经生成好了，先用我开发的小程序来验证下这个是否是有效的。

![](https://g1proxy.wimg.site/sIQk86DfehFrvaadIb8qaAh_j-KuIT3oOmJoI_Ogz9Tg/https://mmbiz.qpic.cn/mmbiz_png/7Zs1OPEmhRespsTG5ib5XjYdMSSNUpIlic3zZhKs1eNHCVhmVIyibB9oBiaQCjBr3QGVvweVEWew3Tic8nicQ3GPCI7g/640?wx_fmt=png&from=appmsg)

 从上图可以看到，这个随机生成的身份证号是有效的，当然我这里只是演示了身份证号，如上图，手机号码也是可以生成的，再验证一下，
