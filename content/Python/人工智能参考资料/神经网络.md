神经网络一般由多个层组成，比如全连接层、卷积层、池化层等，使用不同的模块可以构建出不同的神经网络。本文我们将使用Python从零始构建神经网络。

对于神经网络来说，我们输入数据到神经网络中，数据从一层流向另一层，直到数据最终输出。当数据输出时，我们就可以计算预测值与实际值的误差，再根据误差相对于参数本身的导数来调整给定的参数（权重和偏差），然后对这个过程进行迭代，最终训练出可供使用的神经网络模型。其中，数据从输入到最终输出称为前向传播，根据误差对参数的导数对参数调整称为反向传播，反向传播也是最为重要的一环。当我们对模型进行修改，例如增加或者删除某些层，那么网络的输出就会改变，这会改变误差对于参数的导数。因此为了能在改变网络架构、激活函数以及损失函数的同时计算导数，我们需要单独实现每一层。

在我们可能创建的每一层（全连接层、卷积层、池化层等）都有一个共同点：每一层都有输入和输出数据。

![](https://g1proxy.wimg.site/sBfrNyMbp6e1HWjlZly22vX-_yUuWLBi7s53sIpH3Gwo/https://mmbiz.qpic.cn/sz_mmbiz_png/E2Y5iaDTbrZP4GTlPu3iaz1Yho4MwIqeiaQGIhheHNkJ9D1GIyYv9nI74PV4XxxzftgFljsfRZn6nPatbtiajy8wQA/640?wx_fmt=png&from=appmsg)

且前一层的输出是下一层的输入，为前向传播。我们将输入数据提供给第一层，然后每一层的输出成为下一层的输入，直到网络的最后一层。通过将神经网络输出的结果Y与实际值Y\*进行比较，可以计算出误差E。通过调整网络中的参数来使误差最小化，这就是反向传播。

![](https://g1proxy.wimg.site/slHw86aGH69sMjQ46P00nx64NsmIJiEqWrgB0zB9yfaY/https://mmbiz.qpic.cn/sz_mmbiz_png/E2Y5iaDTbrZP4GTlPu3iaz1Yho4MwIqeiaQzKwJ1sjnd0QE6wyEwKz1W6Nr6gOwObrPJD82ExRnJGgt9uEXx6QCMg/640?wx_fmt=png&from=appmsg)

假设我们给一个层提供误差相对于其输出的导数(∂E/∂Y)，那么它必然能够提供误差相对于其输入的导数(∂E/∂X)。

![](https://g1proxy.wimg.site/sw3RluFbdlZB5kLABeo-ngaE6sqgzUN5lsetgqLaKa4A/https://mmbiz.qpic.cn/sz_mmbiz_png/E2Y5iaDTbrZP4GTlPu3iaz1Yho4MwIqeiaQWJNU9ianSdVjSHZpaHqVITf4XkWibpibvGHDhLDBaI0A9GVrKvHgGOPXQ/640?wx_fmt=png&from=appmsg)

一层的输出是下一层的输入。这意味着一层的 ∂E/∂X 是前一层的 ∂E/∂Y

编写全连接层的代码：  

`import numpy as np` `from layer import Layer` `  
` `class Dense(Layer):` `    def __init__(self, input_size, output_size):` `        self.weights = np.random.randn(output_size, input_size)` `        self.bias = np.random.randn(output_size, 1)` `  
` `    def forward(self, input):` `        self.input = input` `        return np.dot(self.weights, self.input) + self.bias` `  
` `    def backward(self, output_gradient, learning_rate):` `        weights_gradient = np.dot(output_gradient, self.input.T)` `        input_gradient = np.dot(self.weights.T, output_gradient)` `        self.weights -= learning_rate * weights_gradient` `        self.bias -= learning_rate * output_gradient` `        return input_gradient` `  
`

接下来对激活层进行编码：

`import numpy as np` `from layer import Layer` `  
` `class Activation(Layer):` `    def __init__(self, activation, activation_prime):` `        self.activation = activation` `        self.activation_prime = activation_prime` `  
` `    def forward(self, input):` `        self.input = input` `        return self.activation(self.input)` `  
` `    def backward(self, output_gradient, learning_rate):` `        return np.multiply(output_gradient, self.activation_prime(self.input))`

`import numpy as np` `from layer import Layer` `from activation import Activation` `  
` `class Tanh(Activation):` `    def __init__(self):` `        def tanh(x):` `            return np.tanh(x)` `  
` `        def tanh_prime(x):` `            return 1 - np.tanh(x) ** 2` `  
` `        super().__init__(tanh, tanh_prime)`

到目前为止，对于给定层，我们假设∂E/∂Y已给出（由下一层）。但是最后一层会发生什么呢？如何得到∂E/∂Y？我们需要手动给出，这取决于我们如何定义损失函数。这里我们使用均方误差（MSE）。

使用代码实现：  

`import numpy as np` `  
` `# loss function and its derivative` `def mse(y_true, y_pred):` `    return np.mean(np.power(y_true-y_pred, 2));` `  
` `def mse_prime(y_true, y_pred):` `    return 2*(y_pred-y_true)/y_true.size;`

接着我们来创建一个Network类来创建神经网络。

`def predict(network, input):` `    output = input` `    for layer in network:` `        output = layer.forward(output)` `    return output` `  
` `def train(network, loss, loss_prime, x_train, y_train, epochs = 1000, learning_rate = 0.01, verbose = True):` `    for e in range(epochs):` `        error = 0` `        for x, y in zip(x_train, y_train):` `            # forward` `            output = predict(network, x)` `  
` `            # error` `            error += loss(y, output)` `  
` `            # backward` `            grad = loss_prime(y, output)` `            for layer in reversed(network):` `                grad = layer.backward(grad, learning_rate)` `  
` `        error /= len(x_train)` `        if verbose:` `            print(f"{e + 1}/{epochs}, error={error}")`
