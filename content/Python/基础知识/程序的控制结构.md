# 1 判断语句：
- 由判断条件决定程序运行方向的语句
- 有多少条路，走多少条路。
```python
list=['a','b','c']
if 'a' in list:
    print('yes')
if 'b' not in list:
    print('no')
```

### 2.1.5 程序的异常处理
- try:<语句块 1>except:<语句块 2>
	有异常，不执行 1，无异常，不执行 2
- try:<语句块 1>except<异常类型>:<语句块 2>
	只在限定的异常类型才执行 2
	例：except NameError:
- try:...except:...else:...finally:...
	else:在不发生异常时才执行
	异常=条件，except 与 else 分支
- finally:一定执行
## 2.2 循环结构(条件指出口)
### 2.2.1 遍历循环
- for <循环变量> in <遍历结构>:<语句块>
  逐一提取元素，放入变量，并执行一次语句块
- 计数循环(N 次)
	for i in range(n):
	从 0 至 n-1，遍历数字序列
- 计数循环(特定次)
	for i in range(M,N,K):
	从 M 至 N 以 K 为步长
- 循环语句与 range()函数
	for \<变量> in range (\<参数>)： `#`固定格式，冒号不能省
	<补循环执行的语句>
	<变量>表示循环计数，0 到\<次数>-1，从 0 开始计数，逐渐+1
	例：>>>for i in range (5):
	print(i)
	0 1 2 3 4
	例 2：>>>for i in range(5)：
	print("Hello:",i) # 字符串与变量用“，”连接时，输出结果“，”会变成空格。
	Hello: 0……
- range()函数 ^22bdbe
	- range(m,n)
		从m数到n-1，共n-m个。人观至机观：首同尾减一。
	- range(n)
		产生 0 到 n-1 的整数序列，共n个 
- 遍历字符串
	for c in s:
	把字符串 s 的每个字符逐一放入变量 c
	例：for c in "ab":print(c,end",")结果为：a,b
- 遍历列表
	for item in ls:
	把列表 ls 的每个元素逐一放入变量 item ^cee06e
- 遍历文件
	for line in fi:
	把文件 fi 的每一行逐一放入变量 line

- 遍历字典

## 2.3 random 库
### 2.3.1 import random
### 2.3.2 基本随机数函数
- seed()
	seed(a=None)，设定种子，默认为当前系统时间
- random()
	产生一个 0~1 之间的随机小数，依据为设定的种子
### 2.3.3 扩展随机数函数
- randint(a,b)
	生成一个\[a,b]之间的整数
- getrandbits(k)
	生成一个 k 比特长的随机整数
- randrange(M,N`\[,K]`)
	M,N 之间步长为 K 的随机整数
- uniform(a,b)
	生成一个\[a,b]之间的随机小数
- choice(seq)
	从序列 seq 中随机选择一个元素
- shuffle(seq)
	打乱序列并返回(给赋值变量)
	s=\[1,2];r.shuffle(s);print(s)结果为：\[2,1]
