# 1 #集合
## 1.1 集合类型的定义
- 集合是多个元素的无序组合
- 每个元素唯一，不存在相同元素
- 元素不可更改，非可变数据类型
- 创建集合：{,,,}，建立空集合：set ()
- 相同元素合一，没有固定的顺序
  B=set{"pypy 12"}结果 b={"1","p","2","y"}
## 1.2 集合操作符
- 并：S|T
	**(或)** 返回一个新集合，包括在集合 S 和 T 中的所有元素
- 差：S-T
	返回一个新集合，包括在集合 S 但不在 T 中的元素
- 交：S&T
	**(与)** 返回一个新集合，包括同时在集合 S 和 T 中的元素
- 补：S^T
	返回一个新集合，包括集合 S 和 T 中的非相同元素
- S\<=T 或 S\<T
	返回 True/False，判断 S 和 T 的子集关系
- S>=T 或 S>T
	返回 True/False，判断 S 和 T 的包含关系
- S|=T
	更新集合 S，包括在集合 S 和 T 中的所有元素
- S-=T
	更新集合 S，包括在集合 S 但不在 T 中的元素
- S&=T
	更新集合 S，包括同时在集合 S 和 T 中的元素
- S^=T
	更新集合 S，包括集合 S 和 T 中的非相同元素 ![[Pasted image 20240217042356.png]]
## 1.3 集合处理方法
- S.add (x)
	向集合 S 中增加原本没有的 x
- S.discard (x)
	移除 S 中的元素 x，如没有，不报错
- S.remove (x)
	移除 S 中的元素 x，如没有，报错 KeyError
- S.clear ()
	移除 S 中的所有元素
- S.pop (x)
	从 S 中随机取出并删除该元素，更新 S。若 S 为空报错 KeyError
- S.copy ()
	返回集合 S 的一个副本
- Len (S)
	返回集合 S 的元素个数
- X in S
	判断 S 中元素 x，x 在集合 S 中，返回 True
- X not in S
	判断 S 中元素 x，x 不在集合 S 中，返回 True
- Set (x)
	将其他类型变量 x 转变为集合类型
## 1.4 集合类型应用场景
- 关系比较
	"p" in {"p", 1,2}
	{1,2}>={1,2,3}
- 数据去重
	Ls=\[1,1,2]
	s=set (ls) `#` 转换为集合
	ls=list (s) `#` 转换为列表

  最后一个元素为-1，从右至左为-1，-2……

	  转人观：程序观下标加 1：从 m+1 到 n，即想\[1,2]，要写\[0,2]
	  转程序观：人观下标减 1
- 切片赋值：list\[0:-1]=iterable #原地

### 2.5.5 列表推导式
```python
new_list = [expression for item in iterable if condition] # if为可选参数
```
**各部分详解：**
1. **新列表的初始化符号 \[]**：这表示我们将创建一个新的列表。
2. **表达式 (expression)**：这是针对原始可迭代对象中的每个元素进行计算或操作的部分。这个表达式可以引用 `item`，也可以包含更复杂的逻辑。
3. **for 循环**：这部分定义了用于遍历的可迭代对象（iterable）以及循环变量（item）。对于可迭代对象中的每一个元素，都会执行一次表达式。
4. **条件判断 (if condition)**：这是可选部分，如果提供了条件，则只有当条件为 `True` 时，对应的 `item` 才会被包含在新列表中并执行相应的表达式。
   ```python
	motorcycles=["honda","yamaha","suzuki"]
	motorcycles = [brand for brand in motorcycles if brand != "honda"]  # 列表推导式，某元素之外的所有，组成新列表
	print(motorcycles)
	```
### 2.5.6 拆包 
- a, b, c = numbers     #拆包 #元组 #列表
  numbers是列表或元组，左右数量必须相等
- a, \*rest = numbers  #拆包 #元组 #列表
  a 会被赋予第一个元素 ，而 rest 则是一个新的列表，包含剩余的元素
- args = \[1, 2, 3] ; my_function(\*args) #拆包 #生成器
   args 列表被拆包并作为单独参数传递给 my_function 函数 \*代表所有元素。
  
# 3 #字典
## 3.1 字典类型的定义
- 映射是键 (索引)与值 (数据)的对应关系
	可以想成自定义序号的序列
- 字典是映射的体现
- 字典是键值对的集合，无序可排
- 创建：d={:,:,:,}或 dict ()
-  {\<键 1>:\<值 1>,...\<键 n>:\<值 n>}
- 空{}是字典不是集合
- 通过键获得值，\[]用来索引、增加元素或修改值 (有则改，无则增)
	![[Pasted image 20240217042705.png|500]]
## 3.2 字典处理函数及方法
- Type (x) #字典 #函数
	返回 x 的类型
- Del d\[k]
	删除字典 d 中键 k 对应的值
- K in d #字典
	字典 d 中有键 k，返回 True
- d.keys () #字典 #方法
	返回字典 d 中所有键信息
- d.values () #字典 #方法
	返回字典 d 中所有值信息
- d.items () #字典 #方法
	返回字典 d 中所有键值对信息
- d.get (k,\<default>) #字典 #方法
	键 k 存在，则返回相应值，否则返回 None 或\<default>值
- d.pop (k,\<default>) #字典 #方法
	键 k 存在，则移出相应值，否则返回 None 或\<default>值
- d.popitem () #字典 #方法
	随机从字典 d 中取出一个键值对，以元组形式返回
- d.clear () #字典 #方法
	删除所有键值对
- Len (d) #字典 #函数
  返回字典 d 中元素的个数
