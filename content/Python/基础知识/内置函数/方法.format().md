# 1 字符串类型的格式化
- 可以用于`print()`函数内部，还可以用于其他字符串操作中。
  例如，你可以将格式化字符串赋给变量，或者将其用于字符串拼接。
  下面是一个示例：
```python
name = "Alice"
age = 30
message = "My name is {} and I am {} years old.".format(name, age)
print(message)

```
