**Python 类和对象基础学习笔记**

在 Python 中，所有的数据类型都是对象。类实际上就是创建对象的模板。

# 1 **类（Class）**
类是对具有相同特性或行为的事物的抽象。比如定义一个"人"的类：
```python
class Person:
	pass
```

# 2 **对象（Object）**
类是模板，而对象是根据这个模板创建出来的实例，创建对象的行为叫做实例化。
比如根据 "人" 的类，我们可以创建出 "张三" 这个具体的人（对象）：
```python
zhangsan = Person()
```

# 3 **属性（Attribute）**
类中定义的变量称为属性，用于描述对象的特征。比如，我们可以给 "Person" 类增加一些属性，比如姓名 (name) 和年龄 (age)：
```python
class Person:
	eye = 2
	heart = 1
zhangsan=Person()
print("zhangsan有几只眼睛？",zhangsan.eye)
```
此处定义的 `name` 和 `age` 是类属性，它们属于类对象 Person，被所有 Person 的实例对象所共享。

# 4 **方法（Method）**
类中定义的函数称为方法，用于描述对象的行为。比如，我们可以给 "Person" 类增加一些方法，例如一个打招呼的方法：
```python
class Person:
	def say_hello(self):
		 print("Hello, I am a person.")
```

# 5 **实例属性**
每个实例对象都有自己独立的实例属性空间，用于保存自己的属性值，这些属性与其他实例对象无关，互不影响。
```python
zhangsan = Person()
zhangsan.name = '张三'
zhangsan.age = 25
```
在这里，'张三' 和 25 就是 zhangsan 这个对象的实例属性。

# 6 **初始化方法（**init**）**
当创建一个类的新对象时，Python 会自动调用这个类的 `__init__` 方法。我们通常会把设置实例属性的操作写在这个方法中：
```python
class Person:
	def __init__(self, name, age):
		self.name = name
		self.age = age
```
我们创建新对象时，就可以直接传入初始属性值：
```python
zhangsan = Person('张三', 20)
```

# 7 **继承**
Python 支持类的继承，子类可以继承父类的所有属性和方法，还可以添加自己特有的属性和方法：
```python
class Student(Person):   # Student 类继承了 Person 类
	def study(self):
		print("I am studying.")
```
在这个例子中，Student 类就继承了 Person 类的所有属性和方法，并且添加了一个新的方法 `study`。

以上就是关于 Python 中类和对象基础知识的学习笔记。
