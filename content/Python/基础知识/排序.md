## 0.1 1\. 冒泡排序（Bubble Sort）

冒泡排序是一种简单但效率较低的排序算法。它通过不断比较相邻元素并交换位置来实现排序。具体而言，它从列表的第一个元素开始，将较大的元素向右移动，直到整个列表按照升序排列。

`def bubble_sort(arr):  
    n = len(arr)  
    for i in range(n):  
        for j in range(0, n-i-1):  
            if arr[j] > arr[j+1]:  
                arr[j], arr[j+1] = arr[j+1], arr[j]  
`

冒泡排序的时间复杂度为O(n^2)，因此对大型数据集进行排序时效率较低。然而，当输入数据已经接近有序时，冒泡排序效果较好。

## 0.2 2\. 插入排序（Insertion Sort）

插入排序是一种简单且高效的排序算法。它逐个将待排序的元素插入到已排序序列中的正确位置，最终得到一个有序序列。

`def insertion_sort(arr):  
    for i in range(1, len(arr)):  
        key = arr[i]  
        j = i-1  
        while j >= 0 and arr[j] > key:  
            arr[j+1] = arr[j]  
            j -= 1  
        arr[j+1] = key  
`

插入排序的时间复杂度也为O(n^2)，但是当输入数据已经接近有序时，插入排序的效率非常高。

## 0.3 3.选择排序（Selection Sort）

选择排序是一种简单但并不高效的排序算法。它不断选择未排序列表中的最小元素，并将其放置在已排序序列的末尾。

`def selection_sort(arr):  
    n = len(arr)  
    for i in range(n):  
        min_idx = i  
        for j in range(i+1, n):  
            if arr[j] < arr[min_idx]:  
                min_idx = j  
        arr[i], arr[min_idx] = arr[min_idx], arr[i]  
`

选择排序的时间复杂度同样为O(n^2)，但由于每次交换的次数较少，相对于冒泡和插入排序来说，选择排序通常会更快。

## 0.4 4.快速排序（Quick Sort）

快速排序是一种高效的分治排序算法。它通过选择一个基准元素，将列表分割成两部分，然后对这两部分进行递归排序，最终得到一个有序序列。

`def quick_sort(arr):  
    if len(arr) <= 1:  
        return arr  
    pivot = arr[len(arr)//2]  
    left = [x for x in arr if x < pivot]  
    middle = [x for x in arr if x == pivot]  
    right = [x for x in arr if x > pivot]  
    return quick_sort(left) + middle + quick_sort(right)  
`

快速排序的平均时间复杂度为O(nlogn)，在实践中通常比其他基于比较的排序算法更快。它在大多数场景下都表现良好，但在处理已经接近有序的数据时效率较低。

## 0.5 5.归并排序（Merge Sort）

归并排序是一种高效的分治排序算法。它将列表分成两个子列表，对每个子列表进行递归排序，然后将排序好的子列表合并成一个有序序列。

`def merge_sort(arr):  
    if len(arr) <= 1:  
        return arr  
    mid = len(arr) // 2  
    left = merge_sort(arr[:mid])  
    right = merge_sort(arr[mid:])  
    return merge(left, right)

def merge(left, right):  
    result = []  
    i = j = 0  
    while i < len(left) and j < len(right):  
        if left[i] < right[j]:  
            result.append(left[i])  
            i += 1  
        else:  
            result.append(right[j])  
            j += 1  
    result.extend(left[i:])  
    result.extend(right[j:])  
    return result

`

归并排序的时间复杂度是稳定的O(nlogn)，因此无论输入数据的分布如何，它都能保证较好的性能。归并排序也可以应用于大型数据集，尤其适合外部排序。

## 0.6 6\. 堆排序（Heap Sort）

堆排序是一种高效的基于完全二叉堆的排序算法。它通过构建最大堆或最小堆来实现排序。

`def heapify(arr, n, i):  
    largest = i  
    left = 2 * i + 1  
    right = 2 * i + 2

    if left < n and arr[i] < arr[left]:  
        largest = left  
    if right < n and arr[largest] < arr[right]:  
        largest = right  
    if largest != i:  
        arr[i], arr[largest] = arr[largest], arr[i]  
        heapify(arr, n, largest)

def heap_sort(arr):  
    n = len(arr)  
    for i in range(n//2 - 1, -1, -1):  
        heapify(arr, n, i)  
    for i in range(n-1, 0, -1):  
        arr[i], arr[0] = arr[0], arr[i]  
        heapify(arr, i, 0)

`

堆排序的时间复杂度为O(nlogn)，性能稳定且较好。它常被用于优先队列和高性能排序场景。

## 0.7 应用场景

不同的排序算法在不同的场景中有着各自的应用。下面是一些常见的应用场景：

冒泡排序：适用于小型数据集或者基本有序的数据，实现简单但效率低下。

插入排序：适用于部分有序的数据集，对近乎有序的数据集效率较高。

选择排序：适用于简单的排序需求，代码简单易懂，但对大规模数据集效率较低。

快速排序：适用于大规模数据集，尤其在处理随机分布的数据时表现出色。

归并排序：适用于大规模数据集，具有稳定的时间复杂度和良好的性能。

堆排序：适用于需要高性能排序的场景，例如优先队列实现。

根据数据规模、分布情况和对稳定性要求的不同，我们可以选择适合的排序算法来提高效率和性能。

## 0.8 结论

Python提供了多种排序算法，每种算法都有自己的特点和应用场景。在实际开发中，根据数据集的规模、分布和对稳定性的要求，选择合适的排序算法可以最大程度地优化排序过程。无论是处理小型数据集还是大型数据集，合理选择排序算法都能帮助我们更高效地完成排序任务。
