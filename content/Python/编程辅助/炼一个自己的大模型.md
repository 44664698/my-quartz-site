原创  渡码  渡码 

> 讲AI，靠得住，蓝色字体求关注

哈喽，大家好。  

今天给大家分享一个开源项目，零代码帮你训练一个自己的大模型。

准确来说是基于开源大模型微调一个自己的大模型，可以在消费级显卡上炼，但至少得是 3090。

项目名叫LLaMA-Factory。名称看起来像是 LLama 专用的，但实际上国内开源的大模型都能支持。

项目使用 Python 开发的，自带 web 界面。  

![](https://g1proxy.wimg.site/seU2n3k1yh_Hd-yjwlD--Dj4XmMj6K4nuesF0NVloUZk/https://mmbiz.qpic.cn/sz_mmbiz_png/PojicEpVKKnicPe40qfLiconXCaMkib2UB8maxfWvjx0XyvYG6G7R01zYGhWBwYiaUHKAwzWSl0puiaSp4mIpJZf54jQ/640?wx_fmt=png&from=appmsg)

项目的优点：  

* 零代码编辑
* 中英文双语界面即时切换
* 训练、评估和推理一体化界面
* 预置 25 种模型和 24 种多语言训练数据
* 即时的训练状态监控和简洁的模型断点管理
