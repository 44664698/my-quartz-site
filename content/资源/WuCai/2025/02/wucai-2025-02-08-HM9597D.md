## 本地部署DeepSeek-R1怎样联网？详细教程来了

## 划线列表

## 全文剪藏
很多读者提到，希望本地部署的DeepSeek-R1有联网功能，今天就来说一下实现方法。

**一、用Ollama本地部署模型（已部署好的，可忽略此节）** 

通过网址：https://ollama.com 下载Ollama。

![](https://g1proxy.wimg.site/s22b6hXW8uTs4zeffsyuPDtXlQ0Y-AccN9M7mmNPwNzc/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4t26kBFQj83oDAOjTsSLd3wnsL94WL3GJHJ5em95rTibKApZ41RIEdiaw/640?wx_fmt=jpeg&from=appmsg)

可选Windows、Linux、macOS多个版本：

![](https://g1proxy.wimg.site/sz-JAHlSYuMOW5UG4dbc6wT8qdPvygfCzKdBp_DPLEm8/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4CP6M1zkVic5kcImWib1DtM3Ue2ibmQjwcqIjnTHdJiaZU3MrNf0LfQ1fKQ/640?wx_fmt=jpeg&from=appmsg)

以Windows为例，下载后直接安装，完成后窗口会自动关闭，然后可以通过系统托盘图标来判断Ollama是否启动：

![](https://g1proxy.wimg.site/siSiQJkt4LqrRbBO3wiX_yCd67ohtdbdxecPcBsY_v2Q/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4BK5zVWYX4Yvghlliar12iaxNRdYFxvZ8T3Ijicgk1MkibhPRoHjghsAOUg/640?wx_fmt=jpeg&from=appmsg)

点击Ollama官网左上方的“Models”按钮，选择DeepSeek-R1：

![](https://g1proxy.wimg.site/swJpsHvsjEhkl9hShhNhqROgbqyW8dhdCtM1nnpQWnPY/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4rEa3NLty6rcibYpFTzmB48ib2hkFdDZJE7ALvTSC5e6dt7S3GzKOuSVA/640?wx_fmt=jpeg&from=appmsg)

进入这个界面，点击下拉菜单选择适合的版本（数字越大，对显存要求越高）：

![](https://g1proxy.wimg.site/sUN-bExoiFt2QFmfI1Jy-uzIVdnqw_InTRliNT_W9Nqc/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4oOCSHSyGU9Q3ArJ7eZ8IpqyhwlqLmiashZPSbW9ljXNfvKheGv9n3DQ/640?wx_fmt=jpeg&from=appmsg)

模型版本和显存需求的大致对应关系：

![](https://g1proxy.wimg.site/sc4FcvfuHMvgt9DND82-NdcCpaOms0wRJRzG82fnRpCc/https://mmbiz.qpic.cn/sz_mmbiz_png/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4Dvmv898LUvtr4EicZl8TsjWppb5pxOjv9vIQOjkkXydciafrwL51icAtg/640?wx_fmt=png&from=appmsg)

我们下载14b的模型，点击此处复制命令：ollama run deepseek-r1:14b

![](https://g1proxy.wimg.site/slqfpw3nZBzfmZ77RgwtoYRW1ZGj3XI9IIE8zcG9e_MM/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4hrQjVUTqBicNu8e0DEBKVMBWvZwkDdewlzwwXXUQAEv3Pro5M1jqYJg/640?wx_fmt=jpeg&from=appmsg)

点击Windows下方菜单栏的视窗标记，在“搜索应用、设置和文档”处输入“powershell”，然后点击“Windows PowerShell”：

![](https://g1proxy.wimg.site/s-ISrpH_69ViVSaH_-o-AmlRzGk5XYmslg98pWcAIAN4/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4BkYlWQpOoUQ1rCoQRSGfAwn4h1L1sh3UmECCn5nRWPjic8pKaLsQcTQ/640?wx_fmt=jpeg&from=appmsg)

在弹出的窗口中，把刚才复制的命令：ollama run deepseek-r1:14b 黏贴并回车，开始下载。

![](https://g1proxy.wimg.site/sfWRP8-Lq3_Q8pPQb0JRegrlsjEz0XMTLmdKJpY_bq2g/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4ZSKry6pLNRfU0BBMhEJWPfUIjrT5ibF8iaRhIAZ5QibVicZc9EHZpEHw0g/640?wx_fmt=jpeg&from=appmsg)

完成后出现“Send a message”的字样，说明成功了。此时可以关闭这个窗口。

**二、下载page-assist插件** 

该插件目前较好地支持Chrome浏览器和火狐浏览器，也支持Edge（需手动安装）。

![](https://g1proxy.wimg.site/sD5NfX_28w1cRZFlOv1zxi7b92Q8L5GO0wV9OsvEP7-M/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4MhMuVbmSn6Iodcj8L5yjJzRJhVCiaibic9Lp88gpfW8bJPibMaiclEHSDiaA/640?wx_fmt=jpeg&from=appmsg)

**1、Chrome浏览器** 

下载网址：https://www.google.cn/intl/zh-CN/chrome

官网下载需要魔法，虽然你可以找到第三方提供的下载，但后续操涉及Chrome商店，还是需要魔法。

安装好Chrome浏览器后，点击右上角的三个点，依次选中“扩展程序”、“访问Chrome应用商店”：

![](https://g1proxy.wimg.site/s_0tZPSzNwfTCuPuAGKjEOCwUihRIzJbEjnVK3lOmQHw/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4SHl9q6ibsJXm1ibicsNqBXia2RAwtsicn7z9cl2nu0S8aNNW5u2Mf0zv90A/640?wx_fmt=jpeg&from=appmsg)

在应用商店的搜索框输入“page assist”，可以找到我们要用的插件，点击它：

![](https://g1proxy.wimg.site/sdWth7NGlJVC9YbGeoTVHztOgYyV0Y6r1Gpkyyylkdc8/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4jQg6uqTibo1vmVJS3XibnO7UAO0ttcvbOZ8wLQibPqS4JicIlvnYXDBlaQ/640?wx_fmt=jpeg&from=appmsg)

点击“添加至Chrome”：

![](https://g1proxy.wimg.site/sHxhCl1d59gZ5rWRb9VLF7xg-C9SSzCPErEps7RhLeqM/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4bYT7QAaMldwHsJlEDq9wBXyOWhnMqSibl80xEmHEYqLnibqk2vXoBnZQ/640?wx_fmt=jpeg&from=appmsg)

弹出提示，点击“添加扩展程序”：

![](https://g1proxy.wimg.site/sNlLKKlMwU9GhyT_65sRTcPhYTpioNwUe8XB7WP9ghXQ/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4vnW6j6ciak5d3ZD3o28a1bulCK50QzyA2epLgy1Et5Q1Sbzerbzs1ibA/640?wx_fmt=jpeg&from=appmsg)

添加完成之后，可以在浏览器上方的扩展程序中找到page-assist，是一个对话泡泡图标：

![](https://g1proxy.wimg.site/sxmaljYxHTWqdR3NEP0VHkQ-qPklh4McI0JwBtWeBfOM/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4Z40hklF2LpKdxjlN45ECOaHbgibOwrlG5a5CsPxnCGN8ibHQFicCDDALA/640?wx_fmt=jpeg&from=appmsg)

**2、火狐浏览器** 

下载网址：https://www.firefox.com.cn

全程无需魔法，对于搞不定网络的朋友，建议用火狐。

安装好火狐之后，点击右上角的这个扩展标记，选择“管理扩展”：

![](https://g1proxy.wimg.site/sj8MZ5DLG38eDfR7JiS7DM_d_vwO7fC8Fg1rr1HIOjtE/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4Ao3lTVFvkdAmGH3U84SoSLwA1l0Yia0a2BP8EcK5vKKJXqCAdMicOEkw/640?wx_fmt=jpeg&from=appmsg)

在“寻找更多附加组件”处搜索“page assist”：

![](https://g1proxy.wimg.site/s1fVwMnnyky2jbJjrOIwwVGA1Zl1VdvmWui2_-ZATSys/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4VCSgc7JpbsPWwIWvib6ebs5br3HKNibibu5yQcbtvHLwwCCgv0kBpN3Hw/640?wx_fmt=jpeg&from=appmsg)

出来的第一个就是，点击它：

![](https://g1proxy.wimg.site/sTFPGlA7wPb5bKBSZUAVhMZdmc5bwZgqtmuRJG29QAew/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe465VDOibmP2ibgrPaibbZT1lvVjkGgeZhdCau8icZSLGVVficcmtMqMXFNhw/640?wx_fmt=jpeg&from=appmsg)

选择“添加到Firefox”：

![](https://g1proxy.wimg.site/s444YlX0gbZBYnoCOwoVBgf4sjnV02d0f2yZfAcD2Kls/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4WurfHibKibsiaEMuvz7dCqqrLYLOZm4LVEgGhZ8bzgbcNmTtf9jjzvb2A/640?wx_fmt=jpeg&from=appmsg)

完成之后，你可以通过点击“管理扩展”的标记，启用page-assist：

![](https://g1proxy.wimg.site/sT-74qPkLPqTR98h6PTAVJw0tLTotbKbYegjvYjQMcpg/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe43PFibe1nLdXPqOC14A7icsYZoTMZPhyIdjzzDEGj8tbJpl9YCnvcKYBA/640?wx_fmt=jpeg&from=appmsg)

**3、Edge浏览器** 

在微软的扩展商店找不到page-assist，所以必须手工安装此插件（需魔法）。

打开“Windows PowerShell”的命令行窗口，依次执行下列命令：

powershell -c "irm bun.sh/install.ps1 | iex"

git clone https://github.com/n4ze3m/page-assist.git

cd page-assist

bun install

bun run build

![](https://g1proxy.wimg.site/snI2ZXi0rhHBEI-4ZTi6PWwASv3sp9G_uykNtGNn3IZ4/https://mmbiz.qpic.cn/sz_mmbiz_png/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4zIweeKkvYRJmDr3uQXR7pMtC7lbib9ZzzSIg6nnDY7Ydq7l3gQQlYIw/640?wx_fmt=png&from=appmsg)

完成后，在你克隆到本地的目录下，可以看到build这个目录：

![](https://g1proxy.wimg.site/s_J9uDDYd2cSSViSPyAOSq_CzFIEXFwryXW_DNM-yslo/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4z0jo1iaGRP8H6LkvzVcBIA2yLtiaIib5xPETDlvt86YhmTpI07eKAgXeQ/640?wx_fmt=jpeg&from=appmsg)

点击Edge右上角三个点点，选择“扩展”：

![](https://g1proxy.wimg.site/sh26VHFITddh8bgnlzQrW522KZCNW-FpjC4Uz66jr60o/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4Mx7sibIkGI9qDNct5jn4JczYmGYwYDPa6esial0UqSGfX5IaTiaXkq9vw/640?wx_fmt=jpeg&from=appmsg)

在弹出的窗口选择“管理扩展”：

![](https://g1proxy.wimg.site/sPuorWhugtvCr6jr_YWr_a1c5oy1td3eA-T-WPo7lqUo/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4mThicSrXkThMDVHawjDIqGOP6kyvkDicvkd3W3xkNfKWTGsbFjPGQJPA/640?wx_fmt=jpeg&from=appmsg)

在这个界面下，点击左边的“扩展”，并点击“开发人员模式”将其开启，此时右边出现一个图标“加载解压缩的扩展”：

![](https://g1proxy.wimg.site/sp92m7gp-MMg1Wa26HckC9UDLB31Ay_eY8PRj2uJIEuA/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4zD6cFGGhapib0hEE9vnItAzEKfFZJ4pPJgibFAhofJhptwmJtK5DG1Ng/640?wx_fmt=jpeg&from=appmsg)

点击它，并找到刚才的build目录下的chrome-mv3子目录，点击“选择文件夹”：

![](https://g1proxy.wimg.site/s_Kxm-Qvr880PEBK8J_J3ACz1ADB3HkVQH39O-1IQD8c/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4zxt0myrAGOwiaSZ77hbib6AJ2ehqL95D302a0cdIp96EYsPcSiaMwgYgA/640?wx_fmt=jpeg&from=appmsg)

**三、page-assist的使用** 

无论你通过哪个浏览器开启page-assist，界面都是一样的，它会检测到你正在运行Ollama：

![](https://g1proxy.wimg.site/s5S8sW2GFro2z-FnDTeeHdyfERNK1J4jAkNr7t19nwZA/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4AvkIwmBrrDBggFdtSInNAdpUicQWian8gHTIDic3vxCiboicbwoQia4uyCfg/640?wx_fmt=jpeg&from=appmsg)

点击上方的下拉菜单，选择你已经安装的模型：

![](https://g1proxy.wimg.site/skCzDa_Z8YV-8DKNUXIVfUH3BwgEzjuTK-Xrh6R_KV8U/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe48WNo68A1ZRicibllN7VoYOqggjgktoibQ5rImtHV1VYGKib0dbD8apYgSQ/640?wx_fmt=jpeg&from=appmsg)

下方对话框的底部有一个地球标志，点击打开，就开启了网络搜索功能：

![](https://g1proxy.wimg.site/sNsGrQLBmpfUYOuGaN-Vm0NhPBaS2mlmsRtdPevmB7t8/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4xialZfbGH0jmTMhrL3Ibia5AomOia8DCrUBVgMvcdB1OdHkAajqNDrCJA/640?wx_fmt=jpeg&from=appmsg)

我们试着提一个需要最新资讯的问题，这是未开启联网的结果：

![](https://g1proxy.wimg.site/sID_CtXYKs4RRNT4FTYnPTZ2ynEh-39ntgjywOm9Zt6c/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe424ehJVGiavgqY7DLSazSOjU1SdDF1yNnKIMz7f9iauCFZCYb2Or66ukg/640?wx_fmt=jpeg&from=appmsg)

这是开启联网的结果：

![](https://g1proxy.wimg.site/sRoWygKBZBJXeqTohR3i43fccqc-1NB2vp9Pwgwgiipw/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4qicKGmaQrGp6HPzwTaiayKXRFNF9EMZb4ro9JqvmbHCvvfsB5BFYSWjQ/640?wx_fmt=jpeg&from=appmsg)

可以看到，新的信息确实被添加到回答里面，底部还附上了信息出处。

再来一个天气预报：

![](https://g1proxy.wimg.site/skaIH0k5Syo-0JMKh96ALQNzd9oSgMgZAtNo67Jb6p3M/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4gibnanW73UcpgD4T6N9SbSblJYLcJEoMQl1J3LdkiaHkmh7wa1o8yOfA/640?wx_fmt=jpeg&from=appmsg)

我们继续对page-assist进行一些设置，让它处于最佳状态。

点击右上角这个齿轮：

![](https://g1proxy.wimg.site/s0ffKjls1PEcmg3mWnZwiqN0W2NkTPnFPQlypNMFn5Yw/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4qR9OMgRvGhIBGsrdsnhJFDPhBujB1JRSeDwFmE4TqRoxH0AymqoO0Q/640?wx_fmt=jpeg&from=appmsg)

在这个菜单下，把“语言”一栏改成“简体中文”：

![](https://g1proxy.wimg.site/suuPWjHSiadf0LJ8hpOJDFQJbvHm0HgSFw26cieNpY7M/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4IiavNEmbIb7FpRcYT1F9ZxE00Igp5IsBo337LfLTDr6A4yrgBRfUICw/640?wx_fmt=jpeg&from=appmsg)

回到主界面，会发现界面已经是中文：

![](https://g1proxy.wimg.site/sYDhrWVa4SA0kATQVv6dxwCpaLbqQVmAJdbJ1CsMO1Dk/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4VNugT66ZMyVCwvYHvz8yrtZDibcZl97D7AzRQx93wX5fibkPzsibPx31A/640?wx_fmt=jpeg&from=appmsg)

同样是点击右上角齿轮进入菜单，往下拉可以找到“管理网络搜索”，这里可以更改使用的搜索引擎。默认的DuckDuckGo搜索对中文很不好用，**建议改成谷歌、百度、搜狗** 。

![](https://g1proxy.wimg.site/sqdpcuFsKyJajEwEe2tCsN-6ZPFBbUnIlSuN0NtNQnDo/https://mmbiz.qpic.cn/sz_mmbiz_jpg/cAmtwrawGCrhdyZaqWl3Of8JCPhWtGe4STM8NibGabfd0oym97NJiaC9Y56u4ETCZhUj8FrIuqxiaAVWibwGJTNuEw/640?wx_fmt=jpeg&from=appmsg)
