## 太奶看完都直呼简单！超详细DeepSeek本地部署+联网搜索以及满血R1体验攻略

## 全文剪藏
如果你着急用DeepSeek深度思考模式，但却总遇到服务器繁忙，这里为你整理了一份来超详细的 DeepSeek 本地部署指南，帮你解燃眉之急。

**注意，由于个人家用电脑正常情况下无法完美部署最大的模型（需要显存量过大），所以本地部署优势在于不受限于网络，本地运行确保隐私安全等优势，且方便本地知识库搭建以及模型微调。** 

**本地部署工具** 

大模型要实现本地部署，需要借助一些模型管理跟运行工具，这里推荐Ollama 。

**访问官网：** 打开浏览器， https://ollama.com/

**选择操作系统：** 进入 Ollama 官网，会自动弹出适配你电脑的软件。

**下载并运行安装包：** 下载完成后，简单几步就开始安装过程。

**完成安装：** 按照安装向导的提示完成安装过程。安装完成后，可以在桌面右上角的状态栏中看到 Ollama 的图标。

![image.png](https://g1proxy.wimg.site/sVNX2NnO4fYmyomAXn6ZrDGCR1NPQ_PpvT_-s-1V1OIU/https://mmbiz.qpic.cn/sz_mmbiz_png/nK2hP8rzBbo278fhkFpUz2YJBfztqiaUw0dIWIOFgk2usGiaD7wAqibaMl3GpTXdia2icGkAianlLNJoyaZ2eakynlBA/640?from=appmsg)

**检查安装状态：** 

**Mac电脑：** 启动台-其他-终端，打开命令提示符。

**Win电脑：** 按下 Win + R 键，打开“运行”对话框，输入 cmd，然后按回车键，打开命令提示符。

通过运行 ollama help 命令，如果命令行没有报错，并且显示了上述帮助信息，说明 Ollama 安装成功。

![image.png](https://g1proxy.wimg.site/sJqaGi29h8Q3S8yDBT1Bkrpa4OnYgjFIy0VWPNgZReqU/https://mmbiz.qpic.cn/sz_mmbiz_png/nK2hP8rzBbo278fhkFpUz2YJBfztqiaUwwehiajgHF3wYCh96KSXTCT0rLmMx1N4oFUb76JO5PLp5WYukWYUWebg/640?from=appmsg)

**选择适合的大模型** 

回到 Ollama 官网，找到并点击 “Models” 选项，进入模型页面。

在 Models 页面中，首页就能看到 “DeepSeek” 模型。

![image.png](https://g1proxy.wimg.site/sL7q0rYyhUSsoiLr9ytmTRVvZIdu9neWE48l7G-5Ttko/https://mmbiz.qpic.cn/sz_mmbiz_png/nK2hP8rzBbo278fhkFpUz2YJBfztqiaUwXjibKUwTJxaoe3GnePZUxrjicsBj8aehcW8RAIAUSbxiaysawlGZibEmPA/640?from=appmsg)

DeepSeek 模型提供了多个参数规模供用户选择，从 1.5B 到 671B 不等。根据你的电脑配置（特别是内存和显存）选择合适的模型规模：

## ![WechatIMG27142 2.jpg](https://g1proxy.wimg.site/smo7bS69NtVh-jXtdH5XFLQi7N9Hi-MN51zJNIb8lbgM/https://mmbiz.qpic.cn/sz_mmbiz_jpg/nK2hP8rzBbo278fhkFpUz2YJBfztqiaUwR5VFtRVHaXm3ttx8AhghQ1NndX2lMYy72h6rM7KFuA9XDZ2DFiaPe7A/640?from=appmsg)根据你的电脑显卡选择合适自己的大模型大小，如下图所示，绿色代表运行无压力，黄色代表卡顿，红色就不建议安装了。

选择好模型之后，复制下面的命令，Mac电脑在终端，Win电脑在 CMD 中运行。


```
ollama run deepseek-r1:1.5bollama run deepseek-r1:7b  ollama run deepseek-r1:8b  ollama run deepseek-r1:14b  ollama run deepseek-r1:32b  ollama run deepseek-r1:70b
```


运行命令后，系统会开始下载模型，下载模型正常网络即可，模型越小，下载过程越短。当看到提示“success”时，就表示安装成功了。

![image.png](https://g1proxy.wimg.site/sxOWtB20l-FhbPfimqhziodQJQcWHATrTAN89aqsSwhU/https://mmbiz.qpic.cn/sz_mmbiz_png/nK2hP8rzBbo278fhkFpUz2YJBfztqiaUwrNVFXYNhc5TlMpDZGErJvNjHlocMPOc8gk4k44CEzncibYMgbYmfGibA/640?from=appmsg)

到这一步，其实你已经可以使用本地的DeepSeek了，但是在终端运行毕竟不方便，体验很差，这里推荐安装一个可视化工具。

**大模型可视化** 

大模型的可视化工具有很多，这里推荐一个极其简单，无需再安装且能实现联网搜索的功能。

**Page Assist 插件** 

这是一款开源、完全免费的浏览器插件，可以完美契合Ollama，

在 github 上的项目地址：https://github.com/n4ze3m/page-assist

目前最新版为 1.4.5。几乎常用的浏览器都能完美支持：

![](https://g1proxy.wimg.site/su5ETaiVpbLz-Gv91otEMzbdonLp6zt7y40Z4bCKqQr0/https://mmbiz.qpic.cn/sz_mmbiz_png/nK2hP8rzBbo278fhkFpUz2YJBfztqiaUwWmHUuLia8rIQD5nZKfqhe05TdbvFQRib68OeY1ze3M6jfLRuQsbdOFyw/640?from=appmsg)

进入插件后，先把语言全部换成中文

![](https://g1proxy.wimg.site/sUctKthKZSc6dEidP9rjQgYmJsaeSaY7YaVN2IqzsD1w/https://mmbiz.qpic.cn/sz_mmbiz_png/nK2hP8rzBbo278fhkFpUz2YJBfztqiaUw63W2MUJskQibiaHtIgVTZSdnzMczMFs9ogsfmdicQfKwib6UWfJ9FrL0Uw/640?from=appmsg)

**联网搜索** 

很多本地部署的UI工具比较麻烦的就是只能运行本地化，不能进行联网搜索，但是Page Assist可以很好的解决这一问题。

然后点击左上角的新聊天，加载好你下载好的大模型，就能开始对话了，勾选下方的联网搜索，大模型就能联网进行深度思考了。

![](https://g1proxy.wimg.site/s-vJ6GBp4XauUctQjpKx4mmcs-EQmjKil0pb0iL-cBa0/https://mmbiz.qpic.cn/sz_mmbiz_png/nK2hP8rzBbo278fhkFpUz2YJBfztqiaUw35rBaLHkSHuZL6clcML7UhHmmKWj27J9JQ3kichK6iafs3ic1sicslxqicQ/640?from=appmsg)

现在你已经可以用你喜欢的方式和自己部署的本地大模型进行聊天互动了。当然让我比较欢喜的是，它就能让你具备搭建知识库跟管理提示词的功能，但这个有点进阶，我放到后面再细讲。

**本地部署的真相** 

虽然本地部署有诸多好处，但我必须明确告诉所有家用电脑本地部署DeepSeek的朋友：

**你的DeepSeek-R1不是满血版！** 

只要你的设备带不动671B的版本，那么下载的“本地版”，都是经过量化、裁剪甚至蒸馏的缩水模型，回答质量肯定跟满血没法比。

有用户反馈，本地部署的模型连简单代码都写不连贯，甚至出现逻辑混乱。

想跑满血版DeepSeek-R1，目前只推荐两个方法

一个是DeepSeek官网（就是那个总崩溃的官网）

**官网** ：https://chat.deepseek.com/ 

二个是目前比较火的硅基流动
