## 划线列表
- 目前没有专门的 Docker 可视化工具可以直接将已安装在 C 盘的程序移动到 D 盘。不过，你可以通过以下步骤手动完成迁移：
- ### 方法一：在安装时指定安装路径
- 在安装 Docker Desktop 时，可以通过命令行参数指定安装路径，将 Docker 安装到 D 盘。以下是具体步骤：
- 1. **下载 Docker Desktop 安装程序**：
- 访问 [Docker 官方网站](https://www.docker.com/products/docker-desktop/)，下载 Docker Desktop Installer.exe。
- 2. **打开命令提示符**：
- 以管理员身份打开命令提示符，并切换到下载文件的目录。
- ```bash
- cd C:\Users\你的用户名\Downloads
- ```
- 3. **运行安装命令**：
- 使用以下命令安装 Docker Desktop，并指定安装路径为 D 盘：
- ```bash
- start /w "" "Docker Desktop Installer.exe" install -accept-license --installation-dir="D:\Program Files\Docker" --wsl-default-data-root="D:\Program Files\Docker\data" --windows-containers-default-data-root="D:\Program Files\Docker"
- ```
- - `--installation-dir`：指定 Docker Desktop 的安装路径。
- - `--wsl-default-data-root`：指定 WSL 数据的存储路径。
- - `--windows-containers-default-data-root`：指定 Windows 容器数据的存储路径。
- 4. **手动创建目录**：
- 在运行安装命令之前，需要手动创建目标目录，否则可能会报错。
- ### 方法二：迁移已安装的 Docker 数据
- 如果你已经安装了 Docker Desktop，并且需要将数据从 C 盘迁移到 D 盘，可以按照以下步骤操作：
- 1. **停止 Docker 服务**：
- 在开始迁移之前，需要先停止 Docker 服务。
- ```bash
- net stop Docker
- ```
- 2. **迁移 Docker 数据**：
- - 找到 Docker 默认的数据目录，通常位于 `C:\Users\你的用户名\AppData\Local\Docker\wsl`。
- - 将该目录下的所有文件和文件夹复制到 D 盘的目标路径，例如 `D:\Docker\wsl`。
- 3. **修改 Docker 配置文件**：
- - 找到 Docker 的配置文件 `config.v2.json`，通常位于 `C:\Program Files\Docker\Docker\resources`。
- - 打开配置文件，找到 `"data-root"` 字段，将其值修改为新的数据路径，例如 `"data-root": "D:\\Docker"`。
- 4. **启动 Docker 服务**：
- 修改配置文件后，重新启动 Docker 服务。
- ```bash
- net start Docker
- ```
- 5. **验证迁移是否成功**：
- 使用以下命令验证 Docker 的数据目录是否已成功迁移到 D 盘：
- ```bash
- docker info | findstr "D:\\Docker"
- ```
- 如果输出中包含 `D:\Docker`，则说明迁移成功。
- ### 注意事项
- - 在迁移过程中，确保目标路径有足够的空间来存储 Docker 数据。
- - 如果你使用的是 WSL 2，还需要迁移 WSL 的数据文件。
- - 在修改配置文件时，确保路径格式正确，避免因路径错误导致 Docker 无法启动。
