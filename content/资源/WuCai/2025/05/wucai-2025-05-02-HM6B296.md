## Syncthing是啥

`Syncthing` 是一个基于 Go 语言开发的超厉害的开源连续文件同步程序工具，能在两台或多台电脑之间，自动帮你同步文件，就像有个小管家，时刻盯着你的文件，一旦有变化，马上给你同步得整整齐齐。

![](https://g1proxy.wimg.site/sK51vVEPBnB8qsfOzKAaSSgNKna7Pt39t24GK7hfExg0/https://mmbiz.qpic.cn/sz_mmbiz_png/MTw0jgOFnMdfP3Gic0c1iasu3FW1FSLvlolB0JPj95Fmuh9OusMNMlDhNViaNUb33LbEhoibGJXdSibuITjfE9w2Qkw/640?wx_fmt=png&from=appmsg)

## 功能特色

* 安全严防死守：Syncthing 对数据安全那是严防死守，绝不让别人轻易窥探或者修改咱们的文件。不管啥时候，都把咱们的数据安全放在第一位，就像给文件加了一把超级牢固的锁。
* 简单易上手：它的操作简单到让人感动！就算是电脑小白，也能轻松驾驭。没有那些复杂的设置，界面也很简洁明了，一看就懂，主打一个轻松同步。
* 自动同步超省心:只要设置好，它就自动帮你同步文件啦！不用你手动一个个传，也不用你时刻盯着。只有在特别必要的时候，才需要你操作一下，主打一个省心省力。
* 兼容性超强:不管你用的是 Windows、Mac 还是 Linux 系统，它都能完美适配，在各种常见电脑上都能跑起来，完全不用担心兼容性问题。

## 安装方式

安装超简单，去 Syncthing 官网，找到对应你电脑系统的安装包，下载下来一路点击 “下一步” 就能安装好啦，就像安装其他普通软件一样简单。

![](https://g1proxy.wimg.site/sieXG3YkuzaTu2MkNY3tBRF2TuS4bnCCfkVxbNuLfW-c/https://mmbiz.qpic.cn/sz_mmbiz_png/MTw0jgOFnMdfP3Gic0c1iasu3FW1FSLvloll7P6HlmjibiclPmB4X45NxXdkmiceVib6d11vPk83HYibpMpxlZ5ibUlUYQ/640?wx_fmt=png&from=appmsg)

项目也支持用Docker来运行，参考官方的Docker指南，命令如下：


```
$ docker pull syncthing/syncthing
$ docker run -p 8384:8384 -p 22000:22000/tcp -p 22000:22000/udp -p 21027:21027/udp \
    -v /wherever/st-sync:/var/syncthing \
    --hostname=my-syncthing \
    syncthing/syncthing:latest

```


安装好打开，会有个简单的设置向导。你就按照提示，给它设置一下要同步的文件夹。

![](https://g1proxy.wimg.site/sDgCA63tVsTPnReVcRWs8VynPkk8RwAKUmXCe78Fm_0Q/https://mmbiz.qpic.cn/sz_mmbiz_png/MTw0jgOFnMdfP3Gic0c1iasu3FW1FSLvloicW1iamvyxGn12icsLkkIYicd4r8MCUjIbv7HxX82DXIA13W2UtquMiblJg/640?wx_fmt=png&from=appmsg)

![](https://g1proxy.wimg.site/seZA6ZrBwc8iEBoxwzl_TMZURiVmCKPpiopvFKEDPK9o/https://mmbiz.qpic.cn/sz_mmbiz_png/MTw0jgOFnMdfP3Gic0c1iasu3FW1FSLvloAn7ssFmfOLexR0HNp3kJsE75Bsnp4At24pamPFWajSqPYYO8XsW9sA/640?wx_fmt=png&from=appmsg)

设置完成，就可以开启同步之旅啦！你在一台设备上修改、添加或者删除文件，Syncthing 就会自动把这些变化同步到其他设备上。
