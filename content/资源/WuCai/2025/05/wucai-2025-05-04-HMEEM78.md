## Windows 最被低估的功能？沙盒模式的逆天用途 
[[星标]]

## 页面笔记


## 划线列表

## 全文剪藏
你是否遇到过以下问题？

* 下载了一个可疑软件，但怕它携带病毒？
* 需要测试某个程序，但不想让它污染主系统？
* 浏览某些高风险网站，担心被恶意脚本攻击？

如果你还在用虚拟机或备用电脑来解决这些问题，那就太Low了！Windows 其实自带一个“用完即焚”的神器——Windows Sandbox（沙盒模式），它可能是系统里最被低估的功能之一。

## **一. Windows Sandbox 介绍** 

![](https://g1proxy.wimg.site/sLvqCE7Ah7v_zg8lZsBoKVO4CmRDhBBo7VeNYdpcDOT0/https://mmbiz.qpic.cn/sz_mmbiz_jpg/C73aewXicfuicRayd9pHibJffLwQz4HZxJKDxLrTy8Bequ2g42fq2jmurFbKDcB3bkHKYY1zic6SzMDuh0abJ5xiaAg/640?wx_fmt=jpeg&from=appmsg)

Windows Sandbox 是微软在 Windows 10 和 Windows 11 专业版及企业版中提供的一项轻量级虚拟化功能，它允许用户在隔离的环境中运行不受信任的软件，而不会影响主机系统的安全性。

Windows Sandbox 底层是一个基于 Hyper-V 的轻量级虚拟机，每次启动时都会创建一个全新的、干净的 Windows 运行环境。用户可以在该环境中运行各种可疑的软件或测试应用程序，而不必担心对主机系统造成任何损害。

一旦 Sandbox 关闭，其中的所有数据和更改都会被清除，从而提供了一种安全的临时测试环境。

**二. 功能特点** 

1. **完全隔离**  
Windows Sandbox 运行的所有进程都与主机系统隔离，不会对主机产生任何影响。
2. **轻量级**  
依赖于 Windows 的内核技术，使用了高效的虚拟化和容器技术，性能较传统虚拟机更高。
3. **一次性环境**  
每次启动时都是全新的 Windows 实例，关闭后所有更改都会被丢弃。
4. **无需额外安装**  
Sandbox 作为 Windows 自带功能，无需下载额外的虚拟机软件。
5. **与主机共享部分资源**  
它可以与主机共享剪贴板、网络和文件等资源，提高使用便捷性。

## **三. 安装与启用** 

### **1\. 确保系统支持 Sandbox** 

要使用 Windows Sandbox，系统需要满足以下要求：

* Windows 10 专业版、企业版或 Windows 11 专业版、企业版。
* 64 位架构的处理器，并支持虚拟化技术（VT-x 或 AMD-V）。
* 至少 4GB 内存（建议 8GB 及以上）。
* 至少 1GB 可用存储空间。
* 需要启用 Hyper-V。

### **2\. 启用 Windows Sandbox** 

Windows Sandbox 默认是关闭的，需要手动启用。

* 打开 控制面板 > 程序和功能 > 启用或关闭 Windows 功能。

![](https://g1proxy.wimg.site/s3QMFV7zW4pxYkwBLF-dAe3J4RfDc9adOjc9bgQF4_yY/https://mmbiz.qpic.cn/sz_mmbiz_png/C73aewXicfu8Rl8Hd0ILKBeMpOicyCyjOGIvGzIoc9wApEqJyV1PpNG5I38AujicHGYibNpkXEuoicLo3iaZ0ZsxiahBQ/640?wx_fmt=png&from=appmsg)

* 找到 Windows Sandbox，勾选它，然后点击 确定。

![](https://g1proxy.wimg.site/sLHyo8nefB-o2-Rm9cHulEt3hhqVqQ3Uub5W7jn9M1Pg/https://mmbiz.qpic.cn/sz_mmbiz_png/C73aewXicfu8Rl8Hd0ILKBeMpOicyCyjOGe53Vr7M4kwtEu33qjRaqUcibBGgdVxE0o3GQ6CvqQ2tSx5vmLGPvZfQ/640?wx_fmt=png&from=appmsg)

* 系统会提示需要重启，重启后功能生效。

需要启用 Sandbox 时，可以在 开始菜单 中搜索“Windows Sandbox”并运行它。

首次启动可能需要几秒钟的时间来初始化环境。

![](https://g1proxy.wimg.site/saqCrH-hNDTXIkCGd4J40Obq3m_BAt9gOlqG7K5GDTN8/https://mmbiz.qpic.cn/sz_mmbiz_png/C73aewXicfu8Rl8Hd0ILKBeMpOicyCyjOG3WtP4nKia2eVRUHDUkldO3nSwT53Jk7n8M1JWpUv8xiaPBjoKnfcTxeQ/640?wx_fmt=png&from=appmsg)

在Sandbox正常启动后，我们就可以将要测试的软件从主机系统拖放到 Sandbox 窗口内，或者使用剪贴板粘贴。然后在 Sandbox 中运行软件，并进行测试了。

## **四. 应用场景** 

对于Windows Sandbox的应用，通常适用于以下场景：

**测试可疑软件** ：可用来运行不明来源的软件，避免主机系统受感染。

**验证系统配置** ：用于测试不同的 Windows 设置和策略。

**开发环境隔离** ：开发者可在 Sandbox 内测试应用，而不会影响主机环境。

**运行一次性任务** ：适用于只需临时运行某些程序的场景，例如打开不信任的文档或运行脚本。

**防止数据污染** ：避免某些实验性操作对主机系统造成污染。

## **结语：** 

尽管Windows Sandbox 存在着一些局限性，但对于需要临时测试应用或执行风险操作的用户而言，它无疑是一个极具价值的功能。  

如果你还没用过，赶紧试试吧！
