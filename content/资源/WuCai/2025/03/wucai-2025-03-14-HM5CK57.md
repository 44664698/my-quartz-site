## NAS上我装了这些软件，真香 
[[星标]]

## 页面笔记


## 划线列表

## 全文剪藏
 Autre  AUTRE 

没NAS之前都是用网盘，可是年年涨价，还只能自己用，给家人用还得再开会员，换了NAS后，日常交个电费就够了， 满足全家人使用。

关于NAS，最主要的还是照片的使用，每次出门玩，都会拍很多照片，然后回来家人互相欣赏，然后就是影音和文件共享。

所以我的NAS上装了以下软件

docker

大多数软件都是基于docker来部署的，写好docker compose 文件，启动就行，就算更换设备，只需要移动docker compose 文件过去就行，真是太方便了。

nginx

docker compose部署，公网好伴侣，内网一般用不上，直接端口访问就行，公网虽然可以直接用，但是不安全，你能访问被人也就能访问，而且公网一般不适合提供网络服务，有nginx加持，可以配置指定设备/指定人访问指定软件，让公网更安全，比如只能全家人的手机使用mt-photos,而不能网页访问。

WireGuard

docker compose部署，内网穿透工具，方便在外面和家里组网，在外可以轻松联通家里网络，开启后，和在家里访问nas一样方便

docker compose部署，相册软件，全家人都在用，每次排外照片回来导入后，全家人都可以欣赏/筛选，也可以同步手机相册，配合nginx可以随时随地使用，真香

qBittorrent

docker compose部署，下载工具，虽然也装了transmission，但是体验下来qBittorrent更方便分类管理

Home Assistant

pve虚拟机部署，智能家居管理平台，连接不同品牌的设备，目前家里使用了米家，海尔，美的等设备，Home Assistant可以方便将所有设备统一管理起来，比如：每次打开海尔燃气灶时就自动打开美的油烟机。

OpenWrt

pve虚拟机部署，独立网卡直通，软路由，网络加持

Gitea

docker compose部署，管理自己的项目代码，相当于一个本地github

jellyfin

docker compose部署，影音文件管理和在线播放

VanNav

![](https://g1proxy.wimg.site/s_t6WWyFkalIEUG__zd04p6tZhbc-TiJLcJB6pWIiq70/https://mmbiz.qpic.cn/sz_mmbiz_png/lXHamMz7sD9X1d8IdEYak36rIW5yX7lwfppntVXze6qxrWvdk7WadMSKUjO6YNsDicjI33unLGGhuiaTIFCp1amA/640?wx_fmt=png&from=appmsg)

docker compose部署，一个简单的导航平台，部署的所有软件都录入，方便导航直接访问，不用再记各种端口了

smb

debian直接安装，配置参数参考飞牛配置，开启文件共享和mac的时间机器备份。无需安装其他软件辅助，当本地盘一样使用，真香。

飞牛

![](https://g1proxy.wimg.site/s3_ToBq4JX3kUt_YGBnK_JeZbGf8oLfXdPUMYnyqQ7Vg/https://mmbiz.qpic.cn/sz_mmbiz_png/lXHamMz7sD9X1d8IdEYak36rIW5yX7lwDfibwiaqmkZnEibRTKLRvza0SpDg37NxG8SNGYNaExW2mauj5BJrNEibiaw/640?wx_fmt=png&from=appmsg)

pve虚拟机安装，影视用着不错，挂载smb，关联百度网盘阿里网盘（虽然速度很慢，但nas不关机，在下载1.7T的视频，还需要165天，慢慢跑吧），影视也直接用smb中的资源，大多数场景直接用飞牛看影视。

以上就是我常用的软件，觉得还不错，还有很多使用频率很低的软件，有些常挂后台，有些用时启动。
