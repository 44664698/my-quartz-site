## 全文剪藏
无论是个人还是企业，在数字化时代都面临着海量信息的管理挑战。如何高效整理、存储和检索这些宝贵的数据，成为了提升生产力的关键。今天，我们将分享一个简单易上手的方法——基于 Cherry Studio + DeepSeek R1 模型+嵌入模型，快速搭建属于你或你的企业的知识库！  

---

**![](https://g1proxy.wimg.site/sg-3u68kTiqluFW6aSKSaNfwqdN3snUfZEATwYLTbArM/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapM73ggA2s5rlBGtanvqR4AZRO3tgZdDRxc28CX66ISkVl8jLw2MSCYIw/640?wx_fmt=png&from=appmsg)** 

Cherry Studio 是一款功能强大且灵活的桌面客户端工具，支持多模型服务，适用于 Windows、Mac 和 Linux 系统。它不仅集成了主流的 LLM 云服务和 AI Web 服务，还支持本地模型运行。

它的核心亮点包括：

* 完整的 Markdown 渲染
* 文件上传与多模态对话
* 智能体创建与管理
* 友好的界面设计与灵活的主题选项

更重要的是，Cherry Studio 能通过可视化界面和远程 API 接口调用各类模型，大幅降低对本地硬件的依赖，为个人和企业提供了一个高效的解决方案。

### 二、搭建知识库详细步骤教程

#### 第一步：下载并安装 Cherry Studio

1. 打开官网：https://cherry-ai.com/download
2. 根据你的操作系统选择对应的版本进行下载。
3. 下载完成后，按照默认安装步骤完成安装（非常简单，无需额外设置）。
4. 安装完成后，启动软件，你会看到如下界面：

![](https://g1proxy.wimg.site/sToNmIIRybmiC_fDtmiRVdx_f2kCVFY62HobVSmjhM6E/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapM7h2ONZTTXcolA5Vv067ibFJXOInsVWCWuvAvPTqM2tEZtP5zHgibPb7A/640?wx_fmt=png&from=appmsg)  

---

#### 第二步：配置 DeepSeek R1 模型

##### 1\. 获取 API 密钥

DeepSeek R1 模型需要通过硅基流动平台申请 API 密钥：

* 直接访问 https://cloud.siliconflow.cn/i/46GCKpPL，注册账号后进入用户中心，点击“API 密钥”生成密钥。

①登录首页，进入到用户中心；

②点击界面左侧的“API 密钥”；

③再点击右上角的“创建 API 密钥”按钮；

④新建完成后，点击自己刚才新建的密钥，复制该密钥并妥善保存。以上步骤如下图所示：

![](https://g1proxy.wimg.site/sY64JAPq5TtxRXhwFHokCfVVsfg1VXA6uLU-TpPLz3_s/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapMkAUtLJNqwUlRhSYFQ2c3ib1y71RBB5CVzK1YLlq7rQd1kV7YAGlWRGA/640?wx_fmt=png&from=appmsg)

> 注意：复制生成的 API 密钥并妥善保存，后续配置会用到！

##### 2\. 添加 DeepSeek R1 模型

在 Cherry Studio 中添加模型和输入AIP秘钥：

* 点击左下角设置 → “添加”按钮，输入“deepseek-ai/DeepSeek-R1”。
* 完成添加后，记得回到 Cherry Studio 配置 API 密钥，并点击右侧的“检查”按钮，确保测试通过。

![](https://g1proxy.wimg.site/syPPDp2mtFaH7pv-GXjLxWWsYNCxGhiyetkg7Fz5SpXQ/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapM6W1icQAbYZWf05dhQNFxRhN1wUBy1CPgauYiccKg0LfAQ3bGicSTJZeDg/640?wx_fmt=png&from=appmsg)

---

#### 第三步：搭建知识库

##### 1\. 添加嵌入模型

嵌入模型是将文字转化为数字向量的核心工具。以下是具体步骤：

1. 在 Cherry Studio 界面中点击“管理”按钮，选择“嵌入模型”。
2. 将所有可用的嵌入模型都添加进去。
3. 确认操作后，你可以在界面中看到已添加的嵌入模型。

![](https://g1proxy.wimg.site/scOSnpnxL7ANmiAvtNUlhEC6zkUjNIRFIwmAU6IP__7Y/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapMbPTic6Mq1UnzNI7ONEPF1ewvVKJz094DuHkhHRILTb3TqDX5iaxlmFww/640?wx_fmt=png&from=appmsg)

> 根据需要可以使用免费的嵌入模型，无需额外 API 密钥。
> 
> ![](https://g1proxy.wimg.site/sNZq1CwIlPU2_tHlMKiunmzWR-XGPIMyounBhuyIaVe8/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapMLxSAI2OFoibfoJoialB87HI5nMT7vkX1Zss1muBmxFxtxcS4IuTAfEsA/640?wx_fmt=png&from=appmsg)  

##### 2\. 创建本地知识库

1. 在 Cherry Studio 左侧工具栏，点击“知识库”图标，选择“添加本地文档”。
2. 输入知识库名称（如“企业管理制度”或“个人学习资料库”），开始创建。
3. 上传文件（支持 PDF、Word、Excel 等多种格式）。例如，你可以上传一份《企业管理制度》或《个人学习笔记》等。

![](https://g1proxy.wimg.site/se7bXG1W43aEs_HFkkuBEjNpgOMYUddlSZI6FYlQOijc/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapM48h6HaeUEc4hMrEK3AXjcMzAyJQEMMjVwV1QYH7ljUxY9sN7sicFyZw/640?wx_fmt=png&from=appmsg)

> ![](https://g1proxy.wimg.site/sqlhIFmvtWRiKIZ0Kcj__Q89R7izs_9re1yX2vxrqIf0/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapMic24PrMF2ezHZDIEyNJOR9LQJS6YXhnamXlpZVldXhLGibQ8eLQL4PicA/640?wx_fmt=png&from=appmsg)  
> 
> 当文件处理完成后，界面会出现绿色对勾，表示成功。

##### 3\. 配置知识库助手

为新创建的知识库添加一个专属助手，例如命名为【⭐️ 企业管理助手】或【⭐️ 个人学习助手】。

选择对话助手及知识库：在 Cherry Studio 的聊天窗口中，点击知识库图标，选中之前创建的知识库  

![](https://g1proxy.wimg.site/sqY7C0Eai1xTsvZKxIuztVumALPGVkFf7kEs1AMZ920s/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapMujFjaA4OicVxu6f1k5Vr22Mia2gX7icMM3YGeb3uvuPHMZmia4f1by7Opw/640?wx_fmt=png&from=appmsg)  

---

#### 第四步：使用知识库

1. 在 Cherry Studio 的聊天窗口中，点击知识库图标，选中刚刚创建的知识库。
2. 开始与助手对话，引用知识库中的内容生成回复。
3. 验证效果：输入出差用车，会给出相关规定，并告诉你是引用哪个文件！

![](https://g1proxy.wimg.site/sQhCgVWEeL7TBL8FMFsU1W5Wv4LSz8O3BZB0faibRf1M/https://mmbiz.qpic.cn/mmbiz_png/5339ReDEibxgR5RoVBaicLcU9DFlT4JapMqnmCfF7ibVzfxKaI1IfibIv9gUWn6KCibx2SdIJc8riaiavCqC5AgUW2jibg/640?wx_fmt=png&from=appmsg)

1. 硬件要求：如果你的设备性能较低，可能会导致运行速度较慢。建议使用性能较强的设备。
2. 数据安全：如果涉及敏感信息，建议使用本地部署而非网页版。
3. 网页版体验：虽然目前网页版可能不够稳定，但未来肯定会逐步优化。
