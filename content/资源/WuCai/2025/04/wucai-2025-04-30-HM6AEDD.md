#### 什么是 Teable？

![](https://g1proxy.wimg.site/swTrmQhFBahr4UiHht-mfJXXxcsdZ_zsoknzyGOmA3Qc/https://mmbiz.qpic.cn/mmbiz_png/KTkWjEKNj2b5Zo55RiaL8H6Oer7fhTX7P6Zvn8MgKBN60NQwJbicRhA9zqPQzneubgQjibe4AzF33ckmD5h0DtSZA/640?wx_fmt=png&from=appmsg)

> Teable是一个开源的AI驱动无代码数据库，使用类似电子表格的界面来创建功能强大的数据库应用。它允许团队实时协作，轻松处理百万行数据，并提供多种视图展示数据。简单来说，它就是一个更强大、更自由的Airtable替代品，而且完全开源！

#### 开源成就

* **GitHub 热度**  Teable 在 GitHub 上拥有 **17.6k stars** ![](https://g1proxy.wimg.site/sZYRTZ2nIL5Ii5xLgJnb4LiL561wqw0FWfzQdH083mv4/https://mmbiz.qpic.cn/mmbiz_png/KTkWjEKNj2b5Zo55RiaL8H6Oer7fhTX7PWUOouUmibYsZEUP7cCt37pcWM594PGhkwXp7SoAeByYokKyNvDEWGgw/640?wx_fmt=png&from=appmsg)
* **开发语言**  由 **TypeScript (97%)**  驱动，辅以 JavaScript、CSS 和其他技术框架开发而成，代码现代化且高效。

#### 快速安装指南

* **克隆代码库** ：


```
git clone https://github.com/teableio/teable.git
cd teable

```


* **到 Docker 目录** ：


```
cd dockers/examples/standalone/

```


* **运行 Docker Compose** ：


```
docker-compose up -d

```
