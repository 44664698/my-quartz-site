#### 什么是 TigerVNC？

![](https://g1proxy.wimg.site/ss80wq7r0EXwY_xTd5qz5C_ShEC7a4zcYur8odq1hpGE/https://mmbiz.qpic.cn/mmbiz_png/KTkWjEKNj2bBmhFGvvHQ8EoHolrLorgX6vgibkcK0qEQdUvjEllLjEvdw9gbrbVmtBfcSGH38OaQgVH517TcKibQ/640?wx_fmt=png&from=appmsg)

> TigerVNC 是一款高性能的、支持多平台的 **远程桌面工具** ，基于 VNC (Virtual Network Computing) 技术。它允许你在本地直接操作远程的图形化界面，而不管目标设备运行 Windows、Linux 还是 Mac 系统。尤其适合需要运行 3D 应用程序或观看高清视频的场景。TigerVNC 使用先进的 Tight 编码技术和 libjpeg-turbo 编解码器，效率非常高，让你轻松实现流畅的远程操作。

#### 功能特点

![](https://g1proxy.wimg.site/s2R_h8QZXrxDQMi_wy4OKAkemDgoHuB386mOIjZsRthM/https://mmbiz.qpic.cn/mmbiz_png/KTkWjEKNj2bBmhFGvvHQ8EoHolrLorgXhuHicVL5j6HXfj7j35tEpiaaluvqQicsbdLia7gnjIbqUe5Nthic1ic8IibFA/640?wx_fmt=png&from=appmsg)

**多平台支持** 

* **Windows** : 提供专属远程桌面服务器 `winvnc`，让 PC 轻松共享屏幕
* **Linux/Unix** : 自带强大的 `Xvnc` 服务和工具，包括桌面密码管理、配置工具 `vncpasswd`、`vncconfig` 等  
![](https://g1proxy.wimg.site/s0i95ntWjdwNLV8uadACQI4acWB0hiz3Wz-nX678W-Uo/https://mmbiz.qpic.cn/mmbiz_png/KTkWjEKNj2bBmhFGvvHQ8EoHolrLorgXMVLTKt8ia4m0fvqRyQWKSWXl3KrBmqKTLpWgcKZ2CUxP20qIApIZZFw/640?wx_fmt=png&from=appmsg)

**高性能编码技术** 

* 使用 **Tight 编码** ，通过 libjpeg-turbo 提高画面压缩效率
* 完美支持高清视频流和 3D 程序运行

**安全性保障** 

* 支持 **TLS 加密**  和高级身份认证扩展，确保远程连接过程中的数据安全

**跨平台兼容** 

* 支持在 **Windows** 、**Linux**  以及 Intel 架构 Mac 上运行，提供本地化安装包
* 常见 Linux 发行版（如 Fedora、Red Hat、Arch）也直接自带 TigerVNC

**用户友好设计** 

* 提供跨平台的 `vncviewer`，让你轻松连接远程桌面
* 提供丰富的文档和命令行工具，帮助开发者和普通用户快速上手

#### 安装指南

下载适配的二进制包 (如 Linux Deb 包或 Windows 安装程序)

**示例：Ubuntu 快速安装指南** 


```
sudo apt install tigervnc-standalone-server tigervnc-viewer
vncpasswd  # 设置 VNC 密码
vncserver   # 启动 VNC 服务

```


**Windows快速使用指南** 

* 下载并安装 Windows 版本
* 双击运行 `winvnc` 启动服务端
* 使用 `vncviewer` 输入远程主机 IP 进行连接
