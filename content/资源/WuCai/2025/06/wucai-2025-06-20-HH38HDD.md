如今，打开多个音乐平台找歌不仅麻烦，还可能陷入各类会员限制和广告中。今天给大家安利一个GitHub上的神级开源项目——**Nuclear** ，一款专注于从免费资源抓取音乐的全能播放器，有了它，听歌就像在逛音乐超市，想要什么直接搜，爽到起飞！

#### Nuclear是什么

![](https://g1proxy.wimg.site/sJXrwMI1JSedV6hO0qktiZbHMc3hGkablCESqJtNp6tw/https://mmbiz.qpic.cn/mmbiz_jpg/KTkWjEKNj2YweG2U3toV5Vju9RdCJunacTKYAM2qKwVRPfqG1NL0jVQLw6yianJmEib0R91mahnhXUhyR8xaYqdg/640?wx_fmt=jpeg&from=appmsg)

> **Nuclear**  是一款开源的免费音乐流媒体播放器，它能将来自多个互联网平台（如 YouTube、SoundCloud 等）的音乐直接整合到一个平台上，免费、无广告！它就像是一个不用花钱的“全开会员版 Spotify”，任何歌、任何专辑，搜了就能听。

#### 开源成就

* **Star数**  GitHub 上已经吸引了 **13.3k 星** （人气爆棚！）。  
![](https://g1proxy.wimg.site/sf3NgEoZlW2kR8BoVaQirvR5ApItJPy1B_vPuf36Pblg/https://mmbiz.qpic.cn/mmbiz_png/KTkWjEKNj2YweG2U3toV5Vju9RdCJunaU9CRrnMItQoWlBCVv5ibCYkRW0UDDJ9MpibjHQC2uwMSFhicVHlmTAQkg/640?wx_fmt=png&from=appmsg)
* **主开发语言**  项目主要用 **TypeScript**  开发完成，同时用到了 SCSS 和 Rust 等技术。

![](https://g1proxy.wimg.site/sSTshOI_MdLhgDt6q2eRmk2d0SR0l3FB1QdA-OHx60wY/https://mmbiz.qpic.cn/mmbiz_jpg/KTkWjEKNj2YweG2U3toV5Vju9RdCJunaCDdkng47StZraune11BibKMSPddR2qBBkRciaKZut4YsiaMVw4ugJRZUQ/640?wx_fmt=jpeg&from=appmsg)

支持 YouTube、SoundCloud、Audius 等音乐平台，轻松找到海量免费歌曲。

#### 安装指南

> 安装这款软件其实一点也不复杂，各个平台的用户都可以轻松体验：

* **Linux**  用户：  

```
flatpak install flathub org.js.nuclear.Nuclear  

```

* **Windows**  用户：  
如果你安装了 Chocolatey，直接用命令安装：  

```
choco install nuclear  

```

* **macOS**  用户：  
拥有 Homebrew 的直接来：  

```
brew install --cask nuclear  

```


安装完成后，打开界面搜索任何你想听的音乐，就可以尽情畅享无拘束的音乐世界了！
