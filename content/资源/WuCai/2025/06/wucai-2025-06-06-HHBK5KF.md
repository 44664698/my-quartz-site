#### FeelUOwn 是什么

![](https://g1proxy.wimg.site/sl8cSNR7YoZCzBTaByfKYAnWBgEe5CV1E4AqCrLhDGMU/https://mmbiz.qpic.cn/mmbiz_png/KTkWjEKNj2aibGAhbic6m5SMh4kM3muiakueb4ZQkiaL0Zn5MmLQbxyqNaguiaqt4NyuDRJnVMX4iaxV3rslRN47o5dw/640?wx_fmt=png&from=appmsg)

> FeelUOwn 是一款基于 Python 开发的开源音乐播放器。它不仅支持主流音乐播放功能，还兼容多平台（Windows、Mac、Linux），通过插件支持全网免费音乐资源库（比如 YouTube Music）。更吸引人的是，它还自带 AI 电台和自然语言转歌单，真正让你“感受你自己的”音乐世界！

#### 安装指南

> 在不同的操作系统上安装 FeelUOwn 十分简单，以下是快速上手指南：

* **Linux**  
通过包管理器一键安装：  

```
yay -S feeluown  # 安装稳定版
yay -S feeluown-netease  # 自选插件
yay -S feeluown-ytmusic

```

* **macOS**  
推荐通过 Homebrew 安装：  

```
brew tap feeluown/feeluown
brew install feeluown

```

* **Windows & macOS**  
从 Release页面下载预打包的安装包，直接使用。
