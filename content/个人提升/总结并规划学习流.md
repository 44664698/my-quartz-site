- 前言：
	- 不以功利为目标的学习和研究是纯粹的，纯粹的研究上限更高，建议大家作为业余爱好来做。如果即是业余爱好，也对工作或生活能有所助益，那当然更好。 
	- 在这资料爆炸、工具堆山的时代，学习最重要的不再是记忆力，而是理解力，记忆力好只能提高效率，记忆力不好，有个好的笔记软件，也就提取时花多点时间，像 Python 那样几十万个库，每个库都有自己的函数和方法，还经常推陈出新，常用的库自然熟能生巧，不常用的库不可能记到那么多，但只要你能理解，就能为你所用。 
	- 学习最可怕的是，有些东西你不知道它的存在，鉴于此，学习也是需要规划的。
		简单从三个方面来规划：资料，工具，步骤

# 1 资料

知己知彼，百战不殆。

## 1.1 现在网络这么发达，资料铺天盖地，但凡我们要做任何事情，都能找到学习资料，美国俩刚毕业的大学生，仅凭网上的公开资料，就设计出了完全具有可行性的原子弹，这都行，还有什么不可能的？

## 1.2 学习的第一步是找资料，主流资料一是书，二是视频，书我推荐“得到”，微信读书也不错，但没前者纯粹。系统的视频课程我推荐“学堂在线”、“慕课网”，还有网易公开课。那些短视频、卖课的就别提了，不是说没亮点，而是盲人摸象。

# 2 工具

兵欲善其事，必先利其器。

## 2.1 人工智能问答式搜索引擎：
kimi，网页版、小程序都有，经我对比，回答不仅有依据，而且最简明扼要质量最高，我已经用来取代搜索引擎了。

## 2.2 笔记软件：
Obsidian，我花了大概半个月来研究这个软件，但现在看来是完全值得的，可以说这个软件是我不惑之年学 Python 的信心来源 ，用好这软件，记忆不好都不叫事。

## 2.3 其他的工具
太多太多，只你往这里面扎，大数据算法就会不断给你推荐无数好用的工具软件。

# 3 步骤

有了资料有了工具，正式开始进入学习。

## 3.1 第一阶段
了解目标领域所有主干分支。不同于在学校填鸭式教育，自学全靠自己推进，了解全貌，才能明白自己在干什么，知道为什么这样干，是不是你感兴趣的，有没有驱动力，对你的人生有没有意义，这些战略层面的东西扫平了，后面就是一马平川。正如《论持久战》之于抗日战争的意义。具体来说，打个比方，学生物，就先了解猫科犬科，至于猫有什么猫犬有什么犬，后面再说。

## 3.2 第二阶段
每个领域的核心重点有所了解，自己设个权重。比方说，我个人认为基础的东西，是权重最高的，必须滚瓜烂熟，就像乘法表之于数学，拼音之于语文。又比方说，学生物，犬科有藏獒有泰迪，那泰迪的权重我就会设得比较高，因为藏獒我有生之年都只遇到过一次，泰迪就不一样了。

## 3.3 第三阶段
精耕细作。

最后，英语不行？这是问题吗？有了工具，图片、视频翻译都不成问题
只要你提步开始前行，并不断推进，一切你曾认为不可逾越的障碍，渐渐都会被扫平。
