obsidian插件：git
**确保 `.gitignore` 文件配置正确**。否则，Obsidian 插件会把几万个 `node_modules` 依赖文件全部传到 GitHub 上，导致仓库爆炸。
- 按 `Ctrl + P` 打开命令面板。
	输入 `Git: Commit-and-sync`。
	按回车。
- 终端：
	1 设置你的用户名（随便取，建议用你的 GitHub 用户名）
	git config --global user.name "44664698"
	2 设置你的邮箱（注意：这里最好填 GitHub 绑定的邮箱）
	git config --global user.email "bbb_bk@163.com"
本地建站：npx quartz build --serve
验证：http://localhost:8080
git push -u origin main
告诉 Git：以后本地的 `main` 分支，默认就推送到 `origin` 的 `main` 分支。一旦设置好，Obsidian Git 插件以后再也不会弹 `No upstream branch` 这个提示了。
