# 1 喷砂(喷丸)
用高速的砂粒流冲击材料表面，以达到清洁、粗糙化或改变表面特性的目的。
- 几乎所有材料（金属（铝合金、不锈钢、碳钢等）、玻璃、塑料、石材等）铝-喷砂蓝色氧化-喷砂本色氧化-本色氧化
	- 优点
		- 清洁效果：高速砂流的冲击，能清洁表面。
		- 粗糙化：提高表面粗糙度，提高涂层等附着力。
		- 疲劳强度改善。
		- 应力消除：金属表面的残余应力消除。
	- 缺点：
		- 表面损伤：有过度磨损的风险
		- 环境影响：喷砂过程产生大量粉尘
		- 批量处理成本不高
		- 对基材尺寸有微小影响。
# 2 抛光
- 几乎所有材料，尤其是不锈钢和铝材，常用抛光来提升外观和性能。
- 成本取决于：材料类型和硬度、抛光级别和最终效果要求（普通/镜面）、基材形状、批量大小等。
	- 优点
		- 美观化
		- 耐腐蚀性改善
		- 反射率增强
		- 瑕疵去除
		- 机械性能改善：减少应力集中
	- 缺点：
		- 材料去除
		- 环境影响：粉尘
		- 局限性：某些硬质或脆性材料不适合
		- 的优缺点，适应于什么材料，费用贵不？
利用机械、化学或电化学的方法,降低表面粗糙度。
抛光后能接近不锈钢镜面效果,但易留下指纹。
# 3 拉丝
在金属表面沿一定方向进行直线纹理的加工，形成具有一定光泽和质感的丝状纹理。
-  非铁金属：不锈钢、铝、铜及硬度较高的合金。
	- 优点：
		- 美观：可清晰显现每一根细微丝痕,使金属哑光中泛出细密的发丝光泽,兼备时尚和科技感。
			- 抗指纹
			- 耐磨
		- 附着力增强：利于涂层
	- 缺点：
		- 方向性：纹理可能不适用于某些设计
		- 材料去除：影响精度
		- 成本高：尤其是复杂基材、特殊纹理、细密及手工拉丝
		- 维护：需要定期清洁和维护以保外观
反复用砂纸将铝板刮出线条。
直纹拉丝、乱纹拉丝、旋纹拉丝、螺纹拉丝。

# 4 高光切削
使用切削工具对材料表面进行高速旋转和磨削，以达到高光泽度的表面处理工艺。
- 金属材料，尤其是不锈钢、铝合金、铜合金等
	- 优点：
		- 高光泽度：甚至镜面效果
		- 高精度
		- 无需额外涂层或抛光
	- 缺点：
		- 成本高
		- 加工时间长：尤其是复杂基材
		- 材料去除：可能会去掉较多材料
		- 热影响：尤其是硬质材料
采用精雕机将钻石刀加固在高速旋转的精雕机主轴上去切削零件,在产品表面产生局部的高亮区域。
切削高光的亮度受铣削钻头速度的影响,钻头速度越快切削的高光越亮,反之则越暗并容易产生刀纹。
高光切削在手机的运用中特别多,如iphone5,近年来部分高端电视机金属边框采用了高光铣削工艺,加之阳极氧化及拉丝工艺使得电视机整体充满了时尚感与科技的锐利感。
# 5 阳极氧化
在金属表面形成一层致密的氧化膜来提高材料的耐腐蚀性、耐磨性和装饰性。
- 铝、铝合金。
	- 优点
		- 耐腐蚀
		- 耐磨
		- 绝缘
		- 美观：可以单色整体着色，如本色氧化、金(银/黑)色氧化
		- 附着力增强
		- 环保：工艺相对环保
	- 缺点
		- 材料限制：不适用于铝及其合金以外的材料
		- 成本高：尤其是特殊颜色或厚膜
		- 膜层厚度有限：硬度高但厚度薄
		- 工艺时间长
铝及其合金在相应的电解液和特定的工艺条件下,由于外加电流的作用下,在铝制品(阳极)上形成一层氧化膜。
阳极氧化不但可以解决铝表面硬度、耐磨损性等方面的缺陷,更能延长铝的使用寿命并增强美观度,已成为铝表面处理不可缺少的一环,是目前应用最广且非常成功的工艺。
# 6 双色阳极氧化
在传统的阳极氧化基础上增加了额外的步骤来实现两种颜色的效果。
- 铝合金
	- 优点：
		- 耐腐蚀
		- 硬度提高
		- 绝缘
		- 美观：赋予特定区域不同的颜色。通过双色之间的对比,更能体现出产品的高端、独特外观。
	- 缺点：
		- 颜色有限
		- 易见划痕
		- 易碎、易裂纹，少韧性
		- 耐热性低：高温下易裂纹或剥落
		- 工艺复杂,成本略高于单色阳极氧化。

# 7 钝化
通过在金属表面形成一层保护膜来提高金属的耐腐蚀性和耐磨性
原理：金属由于介质的作用生成的腐蚀产物如果具有致密的结构，形成了一层薄膜，紧密覆盖在金属的表面，则改变了金属的表面状态，显示出耐腐蚀的贵金属性能，这层薄膜就叫钝化膜。
- 几乎所有金属，常见于不锈钢、铝/镁合金。
	- 优点：
		- 耐腐蚀性提高显著
		- 耐磨性：因硬度有所增加
		- 无需额外涂层：钝化层可作为保护层
		- 工艺简单
		- 环保性：比电镀或喷涂环保
	- 缺点：
		- 层薄且不均：可能在某些区域不均匀。
		- 外观限制：通常不改变金属本色。
		- 耐热性有限：高温下会分解或失效

# 8 发黑
在钢铁表面形成一层黑色的四氧化三铁（Fe3O4）保护膜，有效提高钢件的防锈能力。
- 铁基材料，如碳钢、合金钢等钢铁制品
	- 优点
		- 防锈：一定程度
		- 不易剥落
		- 对基材尺寸影响极小
		- 美观
		- 成本低
	- 缺点
		- 厚度有限<3um
		- 耐热性差，高温易脱落或氧化
		- 易损
# 9 蚀刻
去除金属材料的部分区域，形成所需的图案或形状。
- 所有金属，常见于不锈钢、铜及其合金、钼片等。
	- 优点：
		- 线条和图案的
			- 高精度
			- 灵活性：任何形状
		- 一致性：不改变基材性质
		- 无毛刺
		- 湿法成本低
	- 缺点
		- 干法成本高
		- 缺点集中于工艺端，如化学处理、设备与化学药品成本、控制难度等。
通过化学或物理手段去除金属材料的部分区域，形成所需的图案或形状。
通过制版曝光，显影后，将要蚀刻区域的保护膜去除，在蚀刻时使金属接触化学溶液，使用两个阳性图形通过从两面的化学淹磨达到溶解腐蚀的作用，形成凹凸或者镂空成型的效果。工艺上有两种方式实现即：曝光法、网印法
# 10 镀铬
通常作为多层电镀的最外层
- 钢铁(碳钢、不锈钢)、铜及其合金、铝及其合金、某些经过适当处理的塑料。
  - 优点
	  - 耐腐蚀性：极佳，化学稳定性好
	  - 硬度高：耐磨优异
	  - 光泽度高：不变色，长久保持反光能力
	  - 易清洁
  - 缺点
	  - 成本高：尤其是贵金属或复杂基材(易漏镀)
	  - 工艺端
		  - 污染环境
		  - 技术要求高
	  - 脆：硬却脆，受冲击易产生裂纹
尽管镀铬的费用较高，但它所带来的优异耐腐蚀性、硬度和美观度使其在一些特殊领域得到广泛应用，如汽车行业、家具制造等。
# 11 镀锌
镀锌是将钢铁或其他金属表面覆盖一层锌以增加其抗腐蚀性能的工艺。有效地保护金属表面免受氧化、腐蚀和其他环境损害。
- 主要适用于碳钢、不锈钢等。
	- 优点
		- 耐腐蚀性：良好，延长使用寿命
		- 美观：光滑有光泽，可进行后处理添加颜色
		- 成本低、速度快
		- 延展性：使基材成型简单化，不影响基材加工性能
		- 对基材尺寸影响极小
	- 缺点
		- 高温不适：会熔化
		- 薄：不能抵御严酷的腐蚀环境
		- 易剥落：表面受损时
		- 不适用于入溶液
		- 氢脆


# 12 镀镍
将镍沉积在其他金属表面上。改善金属零件的耐腐蚀性能、增加硬度和提升美观。
- 主要适用于钢铁、铜、铝等金属材料。
	- 优点：
		- 耐腐蚀性：优异。
		- 硬度提高：增加硬度和耐磨性(比镀锌高，比镀铬低)
		- 美观：表面光滑闪亮。
		- 不易氧化
	- 缺点：
		- 成本高：与镀锌相比。
		- 易划伤：镍层相对较软。
		- 工艺要求高：镀镍过程需要严格的温度、电流和时间控制，操作要求较高。
