# 2 配置系统
1. [x] win10右键菜单
	1. reg.exe add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f 
	2. taskkill /f /im explorer.exe
	3. start explorer.exe
2. [x] 通过组策略锁定目标版本
    1. 按下 ​**`Win + R`**，输入 ​**`gpedit.msc`** 打开组策略编辑器。
    2. 导航至路径：  
        `计算机配置 > 管理模板 > Windows组件 > Windows更新 > 管理从Windows更新提供的更新`。
    3. 双击 ​**​“选择目标功能更新版本”​**，启用策略并填写：
        - ​**目标版本**：`Windows 11`
        - ​**功能更新版本**：`23H2`
    - ​**效果**：系统将仅接收 23H2 的累积更新，阻止 24H2 推送
    - ​**注意事项**：家庭版无组策略编辑器，需改用注册表方法。
