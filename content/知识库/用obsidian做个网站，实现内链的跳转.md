# 1 需要一个能将 Obsidian 笔记（Markdown）转换为 HTML 静态网站的“**发布工具**”。
- 最推荐、最成熟且对 Obsidian 内链支持最好的方案是 **Quartz**。
	1. **Node.js**（推荐 v22 或更高版本）：前往 [nodejs.org](https://nodejs.org/) 下载 LTS 版本安装。安装完成后，在终端运行 `node -v` 确认版本。
    
	2. **Git**：前往 [git-scm.com](https://git-scm.com/) 下载安装。安装后运行 `git --version` 确认。
    
	3. **Obsidian**：你已经在用了，跳过。
    
	4. **GitHub 账号**：没有的话先去注册。
# 2 部署分享：将生成的网站文件夹上传到 GitHub Pages免费托管平台，即可获得一个公开链接分享给他人
